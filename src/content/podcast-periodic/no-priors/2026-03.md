## Overview

March on No Priors was about agentic coding, with both guests saying they now manage agents rather than write code. Notion co-founder Simon Last described how the company and its product are being rebuilt around agents. Andrej Karpathy took the idea further, arguing that the human is now the bottleneck and should step out of the loop where results can be verified.

## Main themes

### From coder to agent manager

- Last says all Notion pull requests are now written by agents; they are larger but better tested. He sees the minimum bar unchanged but the ceiling raised: “You can be like a 100 or 1,000x engineer if you use the tools right now” ([Simon Last](/podcasts/no-priors/2026/03/from-coder-to-manager-navigating-the-shift-to-agentic-engineering-with/)).
- Karpathy says he has barely typed a line of code since December and now delegates almost all of it. He feels nervous when subscription quota goes unused, much as he once did with idle GPUs ([Karpathy](/podcasts/no-priors/2026/03/andrej-karpathy-on-code-agents-autoresearch-and-the-loopy-era-of-ai/)).
- Both guests switch between Claude Code and Codex, and Last prefers CLI tools ([Simon Last](/podcasts/no-priors/2026/03/from-coder-to-manager-navigating-the-shift-to-agentic-engineering-with/), [Karpathy](/podcasts/no-priors/2026/03/andrej-karpathy-on-code-agents-autoresearch-and-the-loopy-era-of-ai/)).
- Last warns that done badly, agent-driven development produces slop, and says Notion feels messier with many more prototypes. He wants structured tools such as a Kanban board rather than 100 chat threads ([Simon Last](/podcasts/no-priors/2026/03/from-coder-to-manager-navigating-the-shift-to-agentic-engineering-with/)).

### Notion rebuilt around agents

- Last says Notion's goal is now “the best tool for humans to manage agents to do the work for them” ([Simon Last](/podcasts/no-priors/2026/03/from-coder-to-manager-navigating-the-shift-to-agentic-engineering-with/)).
- After AI Writer in February 2023 and workspace Q&A in October 2023, Notion tried to build an agent three or four times before shipping a personal agent. Custom agents followed; they start with no access and run in the background once granted it ([Simon Last](/podcasts/no-priors/2026/03/from-coder-to-manager-navigating-the-shift-to-agentic-engineering-with/)).
- Notion rewrites its AI harness about every six months, and Last calls sticking with one design a common mistake. Its people team is one of the heaviest users of custom agents ([Simon Last](/podcasts/no-priors/2026/03/from-coder-to-manager-navigating-the-shift-to-agentic-engineering-with/)).

### Loops that run without you

- Karpathy describes AutoResearch as giving agents an objective, a metric and boundaries, then letting them run. An overnight run on his tuned repo found settings he had missed, such as weight decay on value embeddings ([Karpathy](/podcasts/no-priors/2026/03/andrej-karpathy-on-code-agents-autoresearch-and-the-loopy-era-of-ai/)).
- He imagines a research organization as a set of markdown files that can itself be optimised. He warns this works only where results are verifiable, because models stay jagged ([Karpathy](/podcasts/no-priors/2026/03/andrej-karpathy-on-code-agents-autoresearch-and-the-loopy-era-of-ai/)).
- He credits Peter Steinberger's OpenClaw with persistence, memory and personality. His home claw, Dobby, now runs his lighting, HVAC and security camera and replaced six apps ([Karpathy](/podcasts/no-priors/2026/03/andrej-karpathy-on-code-agents-autoresearch-and-the-loopy-era-of-ai/)).

### Agents as customers, and open models

- Karpathy argues that many bespoke apps should become API endpoints, since “the customer is not the human anymore” ([Karpathy](/podcasts/no-priors/2026/03/andrej-karpathy-on-code-agents-autoresearch-and-the-loopy-era-of-ai/)).
- Notion replaced its verbose JSON API with a markdown dialect for pages and SQLite for databases, because the old format worked badly for agents ([Simon Last](/podcasts/no-priors/2026/03/from-coder-to-manager-navigating-the-shift-to-agentic-engineering-with/)).
- Last says four Chinese open models are now good and much cheaper, and Notion has added one. Karpathy puts open models about 6-8 months behind closed ones and sees systemic risk in closed-only intelligence ([Simon Last](/podcasts/no-priors/2026/03/from-coder-to-manager-navigating-the-shift-to-agentic-engineering-with/), [Karpathy](/podcasts/no-priors/2026/03/andrej-karpathy-on-code-agents-autoresearch-and-the-loopy-era-of-ai/)).
- On jobs, Karpathy expects digital work to change first and is cautiously optimistic about demand for software engineers ([Karpathy](/podcasts/no-priors/2026/03/andrej-karpathy-on-code-agents-autoresearch-and-the-loopy-era-of-ai/)).
