## Overview

November so far on The Pragmatic Engineer has centred on the software factory: teams building agentic systems that produce code, rather than writing it themselves. Satya Nadella and Harjot Gill both argued that verification is now the hard part. Maude Lemaire added a scaling engineer's view, with a sceptical take on AI for performance work.

## Main themes

### Software factories

- Nadella says code has moved from being the input to being the output of software work, so specification and intent matter more. He says onboarding is easier in a software factory because everything is documented and can be queried ([Satya Nadella](/podcasts/pragmatic-engineer/2026/11/software-engineering-after-code-becomes-cheap-with-satya-nadella/)).
- His brownfield examples include an agentic ops system for about 500 Azure fiber operators and a Windows pipeline from crash traces to fixes ([Satya Nadella](/podcasts/pragmatic-engineer/2026/11/software-engineering-after-code-becomes-cheap-with-satya-nadella/)).
- Gill says he merged more than 5,000 PRs in a month by keeping fleets of agents busy. One agent ran for six weeks to build a write-ahead log in Rust, now in production, without him reading the code ([Harjot Gill](/podcasts/pragmatic-engineer/2026/11/software-factories-and-code-reviews-with-harjot-gill/)).
- Nadella says GitHub Copilot caught up with Cursor on agent mode, but Anthropic's model then made the CLI the form factor ([Satya Nadella](/podcasts/pragmatic-engineer/2026/11/software-engineering-after-code-becomes-cheap-with-satya-nadella/)).

### Verification over code review

- Nadella argues that “In a world where code generation has become cheap, what has become hard is verification”. He favours a separate model family as critique ([Satya Nadella](/podcasts/pragmatic-engineer/2026/11/software-engineering-after-code-becomes-cheap-with-satya-nadella/)).
- Gill says “the human code review is dead, but the human review is not dead”. CodeRabbit humans review releases rather than PRs, and engineers on a review-exempt list lose that right after enough regression strikes ([Harjot Gill](/podcasts/pragmatic-engineer/2026/11/software-factories-and-code-reviews-with-harjot-gill/)).
- Gill calls agents verifying their own work hill climbing, using TLA+ models, Lean theorems, simulations, emulated cloud APIs and watched rollouts ([Harjot Gill](/podcasts/pragmatic-engineer/2026/11/software-factories-and-code-reviews-with-harjot-gill/)).
- Lemaire uses mutation tests so LLM-written tests actually cover edge cases ([Maude Lemaire](/podcasts/pragmatic-engineer/2026/11/scaling-slack-and-github-with-maude-lemaire/)).

### Scaling Slack and GitHub

- Lemaire describes event floods at Slack: an IBM admin logged into about 30 workspaces got each shared message 30 times, and power users were also Slack's biggest champions ([Maude Lemaire](/podcasts/pragmatic-engineer/2026/11/scaling-slack-and-github-with-maude-lemaire/)).
- When she joined GitHub in 2024, pull requests and issues ran on only 16 shards. Active Record hid query costs, and the repo home page made over 100 MySQL queries across three clusters ([Maude Lemaire](/podcasts/pragmatic-engineer/2026/11/scaling-slack-and-github-with-maude-lemaire/)).
- On AI, she says “It has not helped me with performance optimizations, basically, at all.” At Cursor, Opus proposed parallelising tasks that only about 1% of users ran ([Maude Lemaire](/podcasts/pragmatic-engineer/2026/11/scaling-slack-and-github-with-maude-lemaire/)).

### Owning the intelligence and paying for it

- Nadella argues that coupling harness, model and memory means lock-in, and that firms need private evals. He calls decision models the stored procedure of the intelligence era ([Satya Nadella](/podcasts/pragmatic-engineer/2026/11/software-engineering-after-code-becomes-cheap-with-satya-nadella/)).
- Gill says CodeRabbit spends several million dollars a month on tokens, and built its own CI after a vendor quoted about $13 million a year ([Harjot Gill](/podcasts/pragmatic-engineer/2026/11/software-factories-and-code-reviews-with-harjot-gill/)).
- Gill argues $8 million seed rounds are no longer enough; Orosz says that holds mainly for AI dev-tool startups ([Harjot Gill](/podcasts/pragmatic-engineer/2026/11/software-factories-and-code-reviews-with-harjot-gill/)).
