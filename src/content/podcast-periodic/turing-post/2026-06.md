## Overview

June on Turing Post had two Microsoft-side guests, and agentic coding was central to both. GitHub's Mario Rodriguez described what agents are doing to the platform and its product design. Sarah Bird of Microsoft's Responsible AI team explained why the same shift forces a rethink of human oversight.

## Main themes

### Agents reshape GitHub

- Rodriguez says model capabilities jumped around December 2025, so agents no longer needed constant correction and could take on longer, better tasks ([GitHub](/podcasts/turing-post/2026/06/github-in-2026-how-ai-agents-are-changing-how-developers-work/)).
- He says growth compounds: more PRs bring more Actions runs and security scans. Agents opened 17 million PRs in March alone, and GitHub is moving load to Azure after one data center hit its limit ([GitHub](/podcasts/turing-post/2026/06/github-in-2026-how-ai-agents-are-changing-how-developers-work/)).
- Host Ksenia Se raised Copilot's move to usage-based billing on June 1. Rodriguez points to the auto setting, which routes simple requests to small models and hard ones to frontier models ([GitHub](/podcasts/turing-post/2026/06/github-in-2026-how-ai-agents-are-changing-how-developers-work/)).

### Designing for agents and people together

- Rodriguez frames GitHub's job as low floor, high ceiling: easier creation for newcomers and more power for experts. He argues GDP growth comes from human creation, and that there were probably other Mozarts who never had a piano ([GitHub](/podcasts/turing-post/2026/06/github-in-2026-how-ai-agents-are-changing-how-developers-work/)).
- The new Copilot app adds canvases, interfaces the agent can read and change and that can in turn drive the agent. He says GitHub's API and UX layers must both become agent-centric ([GitHub](/podcasts/turing-post/2026/06/github-in-2026-how-ai-agents-are-changing-how-developers-work/)).
- He rejects the push to run dozens of agents at once and keeps one to three creative tasks going. On the product name he says: “We named it Copilot because we always think the human is gonna be at the center.” ([GitHub](/podcasts/turing-post/2026/06/github-in-2026-how-ai-agents-are-changing-how-developers-work/)).

### Responsible AI when agents write the code

- Bird says agentic coding is her biggest current concern because responsible AI practice was built on the existing software development lifecycle ([Sarah Bird](/podcasts/turing-post/2026/06/what-responsible-ai-actually-means-in-2026-microsoft-s-sarah-bird/)).
- She argues oversight needs new tools to keep pace: “you always want human oversight, but the question is, where do you put that in the process” ([Sarah Bird](/podcasts/turing-post/2026/06/what-responsible-ai-actually-means-in-2026-microsoft-s-sarah-bird/)).
- Trust, she says, is contextual, and responsibility is shared by model creators, platforms, application developers and users. Fixing everything in the model fails because general-purpose models have legitimate uses for almost anything ([Sarah Bird](/podcasts/turing-post/2026/06/what-responsible-ai-actually-means-in-2026-microsoft-s-sarah-bird/)).
- Her team released open-source tools at Build, including Assert and an agent control specification any runtime can implement. Agents calling tools across organisations can take one-way actions, which raises the stakes ([Sarah Bird](/podcasts/turing-post/2026/06/what-responsible-ai-actually-means-in-2026-microsoft-s-sarah-bird/)).
