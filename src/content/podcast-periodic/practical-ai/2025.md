## Overview

Practical AI's 2025 was about agents and their plumbing: tool calling, MCP and simple agent loops. Coding agents moved to production work, and DeepSeek drew attention to open, efficient models. Later the show turned to people: failed pilots, adoption and how AI reshapes jobs.

## Main themes

### Tool calling, MCP and agent loops

- Daniel Whitenack explains that an LLM only generates text; tool calling is ordinary code around it, and an agent adds LLM orchestration ([Tool calling and agents](/podcasts/practical-ai/2025/02/tool-calling-and-agents/)).
- Pavel Veller says “MCP allows to connect the existing software world to LLMs” ([Orchestrating agents, APIs, and MCP servers](/podcasts/practical-ai/2025/04/orchestrating-agents-apis-and-mcp-servers/)).
- Jared Zoneraich says LLM apps moved from rigid prompt graphs to simple loops with tool calls ([While loops with tool calls](/podcasts/practical-ai/2025/10/while-loops-with-tool-calls/)); Donato Capitella wants agent security built into system design ([Complicated agents](/podcasts/practical-ai/2025/10/dealing-with-increasingly-complicated-agents/)).

### Coding agents and vibe coding

- GitHub COO Kyle Daigle says the core developer skill is now describing problems clearly as Copilot moves to agents ([AI-assisted coding with GitHub's COO](/podcasts/practical-ai/2025/03/ai-assisted-coding-with-github-s-coo/)).
- All Hands AI's Robert Brennan warns that unreviewed vibe-coded code “will just grow into this monster”, so code review must stay ([Open source AI to tackle your backlog](/podcasts/practical-ai/2025/04/open-source-ai-to-tackle-your-backlog/)).
- Igor Nikitin shows actuaries moving to Python, Git and AI assistants ([Reimagining actuarial science with AI](/podcasts/practical-ai/2025/07/reimagining-actuarial-science-with-ai/)).

### Open, efficient and reasoning models

- Whitenack separates DeepSeek's hosted product from its open weights, which can run in isolation, and calls model optionality a business necessity ([Deep-dive into DeepSeek](/podcasts/practical-ai/2025/01/deep-dive-into-deepseek/)).
- IBM's Kate Soule argues most use cases fit models of about 8 billion parameters or less ([IBM's Granite](/podcasts/practical-ai/2025/03/optimizing-for-efficiency-with-ibm-s-granite/)); Samsung's tiny recursive networks beat far larger LLMs on narrow puzzles ([Tiny Recursive Networks](/podcasts/practical-ai/2025/10/tiny-recursive-networks/)).
- NVIDIA's Joey Conway explains how Llama Nemotron adds reasoning, at the cost of more compute ([Finding Nemotron](/podcasts/practical-ai/2025/07/finding-nemotron/)).

### Failed pilots and how adoption spreads

- The hosts argue pilots fail because companies pick one model when they need several models, data integration and architecture ([Cracking the code of failed AI pilots](/podcasts/practical-ai/2025/09/cracking-the-code-of-failed-ai-pilots/)).
- Rajiv Shah says RAG demos are easy but production retrieval and evaluation are hard ([We've all done RAG, now what?](/podcasts/practical-ai/2025/09/we-ve-all-done-rag-now-what/)).
- Scott Meyer treats adoption as bottom-up change management ([Build a workspace of AI agents](/podcasts/practical-ai/2025/03/build-a-workspace-of-ai-agents/)); Jason Beutler says companies must rethink workflows ([Agents that tackle your SOPs](/podcasts/practical-ai/2025/12/beyond-chatbots-agents-that-tackle-your-sops/)).

### AI, jobs and skills

- Chris Benson describes teams shrinking, such as a marketing department of two people with AI tools instead of five ([Workforce dynamics](/podcasts/practical-ai/2025/08/workforce-dynamics-in-an-ai-assisted-world/)).
- Chelsea Linder argues AI reshapes jobs in Indiana rather than removing them ([A state-level case study](/podcasts/practical-ai/2025/10/the-impact-of-ai-on-the-workforce-a-state-level-case-study/)).
- Ramin Mohammadi says AI has erased the junior on-ramp while curricula lag ([The AI engineer skills gap](/podcasts/practical-ai/2025/12/the-ai-engineer-skills-gap/)).
