## Overview

September on Practical AI moved from which model to use towards how agents fit into enterprise systems and the wider web. Guests from Rackspace and VMware Tanzu described layered, governed stacks for running agents, while Demetrios Brinkmann and the founders of Discovered Labs looked at what agents mean for browsing, shopping and search.

## Main themes

### Architecture over model choice

- Chetan Gupta of Rackspace tells enterprises: “Don't marry into any model family because they will swap in and out both for commercial reasons, geopolitical reasons” ([Architecture](/podcasts/practical-ai/2026/09/less-about-models-more-about-architecture/)).
- He describes a layered stack from compute and data up to harnesses, an orchestration layer over many harnesses, and governance and assurance planes. Teams should build their own evals because public benchmarks do not reflect their workloads ([Architecture](/podcasts/practical-ai/2026/09/less-about-models-more-about-architecture/)).
- Gupta extends sovereignty from states to companies: every prompt to an external LLM shares data, context and processes that are IP. He expects the idea to reach individuals too ([Architecture](/podcasts/practical-ai/2026/09/less-about-models-more-about-architecture/)).

### Computer-use agents and agentic commerce

- Demetrios Brinkmann says computer use lets individuals automate almost any web task, such as booking a German driving licence appointment on a site with no API, without waiting for an MCP server ([Computer-Use Agents](/podcasts/practical-ai/2026/09/computer-use-agents-and-the-future-of-the-agentic-internet/)).
- He warns that company-wide computer use would be a security nightmare, and says the Agentic AI Foundation now has over 250 member companies ([Computer-Use Agents](/podcasts/practical-ai/2026/09/computer-use-agents-and-the-future-of-the-agentic-internet/)).
- Brinkmann argues agents skip upsells, so “we're gonna have to start building our ecommerce websites to entice the agents, not the humans.” Chris Benson expects agent-to-agent negotiation interfaces beyond MCP ([Computer-Use Agents](/podcasts/practical-ai/2026/09/computer-use-agents-and-the-future-of-the-agentic-internet/)).
- Harnesses came up twice. Brinkmann says he mostly stopped using Claude Code because models trained into one harness fight third-party ones, while Gupta wants an orchestration layer across harnesses ([Computer-Use Agents](/podcasts/practical-ai/2026/09/computer-use-agents-and-the-future-of-the-agentic-internet/), [Architecture](/podcasts/practical-ai/2026/09/less-about-models-more-about-architecture/)).

### Getting found in AI search

- Liam Dunne says that when people read answers inside an LLM, “the LLM is the new website visitor”, which explains lost organic clicks ([AI Search](/podcasts/practical-ai/2026/09/how-to-get-discovered-in-ai-search/)).
- Ben Moore says Discovered Labs found ChatGPT gave almost a third of retrieval slots to Reddit, though most threads grounded the answer rather than being cited. Upvotes did not correlate with citations; relevance did ([AI Search](/podcasts/practical-ai/2026/09/how-to-get-discovered-in-ai-search/)).
- Moore wants citation rate and share of voice measured with statistical rigour, and Dunne sees long-tail queries letting smaller brands compete with players like HubSpot ([AI Search](/podcasts/practical-ai/2026/09/how-to-get-discovered-in-ai-search/)).

### Deploying agents like apps

- Nick Kuhn of VMware Tanzu argues agents must move off laptops to run continuously. The Tanzu Agent Buildpack deploys an agent defined by a human-readable AGENTS.md file ([AGENTS.md to Enterprise](/podcasts/practical-ai/2026/09/from-agents-md-to-enterprise-deployment/)).
- Kuhn says the main difference from classic apps is file-based memory that disappears on ephemeral cloud instances, so Tanzu is adding a shared memory service ([AGENTS.md to Enterprise](/podcasts/practical-ai/2026/09/from-agents-md-to-enterprise-deployment/)).
- At Broadcom, developers may only use MCP servers hosted on the platform, behind a gateway that limits tools and logs every call. Enterprises want one repeatable pattern they can audit and secure ([AGENTS.md to Enterprise](/podcasts/practical-ai/2026/09/from-agents-md-to-enterprise-deployment/)).
