## Overview

July on Practical AI went back to fundamentals. Daniel Whitenack and Chris Benson marked their 50th episode by explaining the neural network from scratch, and Joel Grus made the case for treating research code like production software. The month closed with a news round-up on AI for the ancient world, game-playing bots and beneficial uses of GANs.

## Main themes

### Learning from scratch

- For episode 50, Whitenack explains a neuron as a small function whose parameters “are often called weights and biases”, fitted by comparing predictions with known outputs ([Episode 50](/podcasts/practical-ai/2019/07/celebrating-episode-50-and-the-neural-net/)).
- The hosts trace the history from McCulloch and Pitts through the perceptron, backpropagation and an AI winter, and explain why model scale pushed training onto GPUs and TPUs ([Episode 50](/podcasts/practical-ai/2019/07/celebrating-episode-50-and-the-neural-net/)).
- Whitenack recommends Joel Grus's Data Science from Scratch for building intuition. Grus says the book teaches maths through Python code rather than equations, starting from vectors as lists of floats ([Episode 50](/podcasts/practical-ai/2019/07/celebrating-episode-50-and-the-neural-net/), [Good science](/podcasts/practical-ai/2019/07/ai-code-that-facilitates-good-science/)).
- Grus says the main reason for the second edition was the move from Python 2.7 to Python 3, with a deep learning chapter added ([Good science](/podcasts/practical-ai/2019/07/ai-code-that-facilitates-good-science/)).

### Software engineering for research code

- Grus says “There's a lot of bad data science code out there.” He argues unit tests and code review have to be sold to data scientists by showing how they make life easier ([Good science](/podcasts/practical-ai/2019/07/ai-code-that-facilitates-good-science/)).
- He recommends testing models on tiny datasets, checking shapes, falling loss and the ability to overfit, and separating well-tested library code from experiment code ([Good science](/podcasts/practical-ai/2019/07/ai-code-that-facilitates-good-science/)).
- Many GitHub projects state no environment, so reproduction is unlikely. Grus also argues data scientists who can write production code avoid an artificial hand-off ([Good science](/podcasts/practical-ai/2019/07/ai-code-that-facilitates-good-science/)).

### AI2 and AllenNLP

- Grus describes the Allen Institute for AI as a nonprofit founded by Paul Allen, with teams including AllenNLP, PRIOR, Semantic Scholar, Aristo and Mosaic ([Good science](/podcasts/practical-ai/2019/07/ai-code-that-facilitates-good-science/)).
- He positions AllenNLP as a PyTorch library with higher-level NLP abstractions, an alternative to raw PyTorch rather than to spaCy. Its CI enforces mypy, Pylint and Sphinx docs, which he says deters researcher contributors ([Good science](/podcasts/practical-ai/2019/07/ai-code-that-facilitates-good-science/)).

### AI for the ancient world, games and good GANs

- Whitenack describes MIT and Google Brain work that deciphered Linear B using cognates, LSTMs and attention without parallel data, and a Netherlands proposal to reconstruct ancient games with machine learning ([Ancient world](/podcasts/practical-ai/2019/07/ai-driven-studies-of-the-ancient-world-and-good-gans/)).
- Benson reports that DeepMind's AlphaStar now plays anonymously on the StarCraft II ladder, limited to the camera view and human-level action rates ([Ancient world](/podcasts/practical-ai/2019/07/ai-driven-studies-of-the-ancient-world-and-good-gans/)).
- The hosts point to GANs generating synthetic imagery to train medical detection models. Benson expects GANs “are going to be a big area of growth over the next few years” ([Ancient world](/podcasts/practical-ai/2019/07/ai-driven-studies-of-the-ancient-world-and-good-gans/)).
- Whitenack contrasts a poker bot trained for about $150 with the energy bill of large NLP models. Both hosts see a shift towards unsupervised methods that need little labelled data ([Ancient world](/podcasts/practical-ai/2019/07/ai-driven-studies-of-the-ancient-world-and-good-gans/)).
