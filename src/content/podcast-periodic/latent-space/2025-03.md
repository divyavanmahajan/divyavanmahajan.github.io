## Overview

March on Latent Space was about agents: how to build them, how to connect them and how to measure them. OpenAI presented its new agents platform, Dharmesh Shah described a network of agents joined through MCP, and Anthropic's David Hershey explained the harness behind Claude Plays Pokémon. A crossover with Redpoint's Unsupervised Learning and a visit from Snipd added the application-layer view.

## Main themes

### OpenAI's platform for agent builders

- Romain and Nikunj present the Responses API as a superset of Chat Completions with built-in web search, file search and computer use. They framed it as delivering on their call that 2025 was the year of agents ([OpenAI Agents Platform](/podcasts/latent-space/2025/03/the-new-openai-agents-platform/)).
- The Agents SDK turns the experimental Swarm library into a supported framework with types, guardrails that run in parallel and tracing. It works with any provider that supports the Chat Completions format ([OpenAI Agents Platform](/podcasts/latent-space/2025/03/the-new-openai-agents-platform/)).
- Romain suggests splitting logic across a triage agent that hands off to specialised agents, instead of one agent loaded with tool calls ([OpenAI Agents Platform](/podcasts/latent-space/2025/03/the-new-openai-agents-platform/)).

### From agents to agent networks

- Dharmesh Shah classifies agents by autonomy, determinism, sync versus async and interaction mode. He predicts that after the year of agents comes the year of multi-agent networks, with hybrid human-agent teams ([Agent Network](/podcasts/latent-space/2025/03/the-agent-network-dharmesh-shah/)).
- Shah says MCP is “one of the better things that's happened in the world of AI, because a standard needed to exist”. He expects agents to need a registry for discovery ([Agent Network](/podcasts/latent-space/2025/03/the-agent-network-dharmesh-shah/)).
- He describes Agent.ai as LinkedIn for agents, with 1.3 million users and about 1,000 published agents, each with a REST API and a place in an MCP server ([Agent Network](/podcasts/latent-space/2025/03/the-agent-network-dharmesh-shah/)).
- In the crossover, swyx says the protocol matters more than any framework, while Alessio calls agent frameworks overhyped. Agent authentication and memory came up in both episodes as open problems ([Crossover](/podcasts/latent-space/2025/03/unsupervised-learning-x-latent-space-crossover-special/), [Agent Network](/podcasts/latent-space/2025/03/the-agent-network-dharmesh-shah/)).

### Harnesses and games as benchmarks

- Hershey calls Claude Plays Pokémon “a pretty straightforward tool using agent”, with three tools, a knowledge base capped near 8,000 tokens and history summarised after 30 messages ([Claude Plays Pokémon](/podcasts/latent-space/2025/03/how-claude-3-7-plays-pok-mon/)).
- Claude 3.7 Sonnet was the first model to make clear progress in Pokémon Red. Vision and spatial navigation stay weak; the stream sat in Mount Moon for more than 50 hours ([Claude Plays Pokémon](/podcasts/latent-space/2025/03/how-claude-3-7-plays-pok-mon/)).
- His best test runs a configuration about 10 times and measures milestones such as gym badges. With each new model, his main change has been deleting corrective prompt text ([Claude Plays Pokémon](/podcasts/latent-space/2025/03/how-claude-3-7-plays-pok-mon/)).

### Where AI applications work

- swyx names coding agents, support agents and deep research as the agents with clear product-market fit. Jordan points to home-services firms that miss 50% of calls as a voice AI opportunity ([Crossover](/podcasts/latent-space/2025/03/unsupervised-learning-x-latent-space-crossover-special/)).
- The hosts argue defensibility comes from velocity, brand and network effects rather than unique data or custom models. The Redpoint side says some category leaders have seen ACVs double ([Crossover](/podcasts/latent-space/2025/03/unsupervised-learning-x-latent-space-crossover-special/)).
- Kevin of Snipd argues podcast apps are still repurposed music players. Cost decides which models Snipd uses ([Snipd](/podcasts/latent-space/2025/03/building-snipd-the-ai-podcast-app-for-learning/)).
