## Overview

June 2023 on Latent Space focused on the product layer: how people should interact with language models and how teams know whether a feature works. Linus Lee and two Amplitude guests covered interface design and feedback, an emergency panel reacted to OpenAI's functions API and price cuts, and George Hotz argued for open, cheap compute.

## Main themes

### AI UX and interface design

- Linus Lee calls flexibility versus intuitiveness one of the core design challenges for building on language models. The same input box styled as a search bar gets keywords, styled as a chat window it gets greetings ([Notion AI](/podcasts/latent-space/2023/06/building-the-ai-ux-scenius-with-linus-lee-of-notion-ai/)).
- He ranks uses in three tiers: content generation, knowledge work and automation. He says most knowledge work is about understanding and deciding, not producing more words ([Notion AI](/podcasts/latent-space/2023/06/building-the-ai-ux-scenius-with-linus-lee-of-notion-ai/)).
- Lee thinks AI UX is “very early in the evolution of that space and that community”, more a scene than a field with shared methods ([Notion AI](/podcasts/latent-space/2023/06/building-the-ai-ux-scenius-with-linus-lee-of-notion-ai/)).
- Stefania Druga says chat should not be the interface for everything, and swyx says the show has been pushing AI UX for a while ([Functions API](/podcasts/latent-space/2023/06/emergency-pod-openai-s-new-functions-api-75-price-drop-4x-context-leng/)).

### Agents, function calling and trust

- The panel reads OpenAI's functions API as an existing prompting pattern now fine-tuned into the model. Riley Goodside notes output can still be malformed or hallucinated ([Functions API](/podcasts/latent-space/2023/06/emergency-pod-openai-s-new-functions-api-75-price-drop-4x-context-leng/)).
- swyx describes a shift from an LLM-core, code-shell design to an LLM-shell, code-core design. Simon Willison suggests exposing a few powerful functions rather than many narrow ones ([Functions API](/podcasts/latent-space/2023/06/emergency-pod-openai-s-new-functions-api-75-price-drop-4x-context-leng/)).
- Willison warns that function calling makes prompt injection more dangerous and wants destructive actions to be reversible or need approval ([Functions API](/podcasts/latent-space/2023/06/emergency-pod-openai-s-new-functions-api-75-price-drop-4x-context-leng/)).
- Lee treats trust and control as two sides of one agent problem, and says users must see which content the AI wrote ([Notion AI](/podcasts/latent-space/2023/06/building-the-ai-ux-scenius-with-linus-lee-of-notion-ai/)).

### Evaluating features from real behaviour

- Joe Reeve says many teams are “nervous of giving thumbs up, thumbs down buttons” because they do not know how to use the feedback ([Amplitude](/podcasts/latent-space/2023/06/from-rlhf-to-rlhb-the-case-for-learning-from-human-behavior-with-jeffr/)).
- At Amplitude, every chart parameter a user edits after generation becomes feedback data. Reeve argues sharing and use of output are better signals ([Amplitude](/podcasts/latent-space/2023/06/from-rlhf-to-rlhb-the-case-for-learning-from-human-behavior-with-jeffr/)).
- Jeffrey Wang thinks first-party behaviour data could one day train a large behavioural model for churn prediction and causal analysis ([Amplitude](/podcasts/latent-space/2023/06/from-rlhf-to-rlhb-the-case-for-learning-from-human-behavior-with-jeffr/)).
- Notion's prompt testing is a hand-rolled regression suite in which a language model grades outputs ([Notion AI](/podcasts/latent-space/2023/06/building-the-ai-ux-scenius-with-linus-lee-of-notion-ai/)).

### Cheaper tokens and open compute

- OpenAI cut embedding prices 75% after an earlier 90% cut. swyx argues embeddings are a form of lock-in, so cheap embeddings suit OpenAI ([Functions API](/podcasts/latent-space/2023/06/emergency-pod-openai-s-new-functions-api-75-price-drop-4x-context-leng/)).
- Testing Notion's autofill on 6,000 pages used 2 to 3 million tokens in about 20 minutes ([Notion AI](/podcasts/latent-space/2023/06/building-the-ai-ux-scenius-with-linus-lee-of-notion-ai/)).
- Hotz started the tiny corp to make restricting access to ML compute structurally impossible. He says tinygrad covers ML models with about 25 ops and that a fast framework must come before custom chips ([tiny corp](/podcasts/latent-space/2023/06/commoditizing-the-petaflop-with-george-hotz-of-the-tiny-corp/)).
- He plans a roughly $15,000 six-GPU tinybox and expects the best models to come from many smaller training runs ([tiny corp](/podcasts/latent-space/2023/06/commoditizing-the-petaflop-with-george-hotz-of-the-tiny-corp/)).
