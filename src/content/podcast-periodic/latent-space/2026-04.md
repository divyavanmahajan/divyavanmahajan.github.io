## Overview

April on Latent Space was about what happens once agents write most of the code. OpenAI, Notion and Shopify described how they engineer harnesses, evals and review around that, while Marc Andreessen and swyx placed it in a wider market story. A second strand covered world models and physical AI, from Moonlake's interactive worlds to Applied Intuition's vehicles.

## Main themes

### Harness engineering when agents write the code

- Ryan Lopopolo's team at OpenAI Frontier built a million-line Electron app in five months without writing code by hand. He argues human attention is the scarce resource, so engineers should build docs, lints, review agents and tools for Codex ([Harness Engineering](/podcasts/latent-space/2026/04/extreme-harness-engineering-for-token-billionaires-1m-loc-1b-toks-day/)).
- Lopopolo adapts the harness to each model: when GPT 5.3 grew less patient, the team moved its build to finish in under a minute. He says models still struggle to take a new product idea to a prototype ([Harness Engineering](/podcasts/latent-space/2026/04/extreme-harness-engineering-for-token-billionaires-1m-loc-1b-toks-day/)).
- Marc Andreessen describes an agent as “LLM plus shell plus file system plus markdown plus cron.” Because its state lives in files, the agent can swap models ([Andreessen](/podcasts/latent-space/2026/04/marc-andreessen-introspects-on-the-death-of-the-browser-pi-openclaw-an/)).

### Evals, review and CI as the new bottleneck

- Sarah Sachs splits Notion's evals into CI regression tests, launch report cards at 80 to 90% pass rates, and frontier evals kept at about 30%. Simon Last says Notion turned its eval system into an agent harness ([Notion](/podcasts/latent-space/2026/04/notion-s-token-town-5-rebuilds-100-tools-mcp-vs-clis-and-the-software/)).
- Mikhail Parakhin says “good model writes code on average with fewer bugs than, than the average human”, but volume pushes more bugs to production. Shopify spends on pro-level models for PR review and sees CI/CD as the main bottleneck ([Shopify](/podcasts/latent-space/2026/04/shopify-s-ai-phase-transition-2026-usage-explosion-unlimited-opus-4-6/)).
- Lopopolo's review agents are told to merge unless an issue is above P2, and most human review now happens after merge ([Harness Engineering](/podcasts/latent-space/2026/04/extreme-harness-engineering-for-token-billionaires-1m-loc-1b-toks-day/)).

### MCP or CLIs for agent tools

- Simon Last prefers CLIs for progressive disclosure and because agents can fix their own tools, but sees MCP's tight permission model as right for narrow agents. Notion's agent now has over 100 tools ([Notion](/podcasts/latent-space/2026/04/notion-s-token-town-5-rebuilds-100-tools-mcp-vs-clis-and-the-software/)).
- Lopopolo is bearish on MCP because the harness injects its tokens into context, and Andreessen says agents need command line tools rather than new protocols ([Harness Engineering](/podcasts/latent-space/2026/04/extreme-harness-engineering-for-token-billionaires-1m-loc-1b-toks-day/), [Andreessen](/podcasts/latent-space/2026/04/marc-andreessen-introspects-on-the-death-of-the-browser-pi-openclaw-an/)).

### World models and physical AI

- Chris Manning and Fan-yun Sun argue world models must be action-conditioned. Moonlake pairs a reasoning model with symbolic tools such as physics engines, then restyles the result with a diffusion model ([Moonlake](/podcasts/latent-space/2026/04/moonlake-causal-world-models-should-be-multimodal-interactive-and-effi/)).
- Applied Intuition's Qasar Younis and Peter Ludwig say “we're not really constrained right now by, like, the intelligence of the models.” Deployment on embedded hardware and statistical validation are the limits ([Applied Intuition](/podcasts/latent-space/2026/04/physical-ai-that-moves-the-world-qasar-younis-peter-ludwig-applied-int/)).
- Both episodes say world models lack clean benchmarks, and swyx names world models as a next frontier ([Moonlake](/podcasts/latent-space/2026/04/moonlake-causal-world-models-should-be-multimodal-interactive-and-effi/), [AIE Europe Debrief](/podcasts/latent-space/2026/04/aie-europe-debrief-agent-labs-thesis-unsupervised-learning-x-latent-sp/)).

### Markets: agent labs, coding wars and the bubble question

- swyx says 2026 is the year coding agents break containment. Agent labs start on frontier models and train their own once they have enough data, while the coding market stays a two-player contest ([AIE Europe Debrief](/podcasts/latent-space/2026/04/aie-europe-debrief-agent-labs-thesis-unsupervised-learning-x-latent-sp/)).
- Andreessen argues this is not a dot-com rerun: today's buyers are cash-rich and every GPU dollar earns revenue at once. He expects regulation and unions to slow adoption ([Andreessen](/podcasts/latent-space/2026/04/marc-andreessen-introspects-on-the-death-of-the-browser-pi-openclaw-an/)).
- Noetik offered a business angle on foundation models in drug development: a licensing deal with GSK that Ron Alfa calls the first of its kind in the space ([Noetik](/podcasts/latent-space/2026/04/training-transformers-to-solve-95-failure-rate-of-cancer-trials-ron-al/)).
