## Overview

October on Latent Space was about getting agents into production. OpenAI's platform team and Vercel's CTO described the tooling they ship for it, while Kyle Corbitt argued that task-specific reinforcement learning is what makes agents reliable. Figma's Dylan Field added the counterpoint that as code gets cheap, design and taste matter more.

## Main themes

### Agent platforms from OpenAI and Vercel

- Sherwin Wu and Christina Huang present AgentKit (Agent Builder, ChatKit, a connector registry and evals) as a response to API customers struggling to reach production. OpenAI's own help site already runs on it ([DevDay 2025](/podcasts/latent-space/2025/10/devday-2025-apps-sdk-agent-kit-mcp-codex-and-why-prompting-is-more-imp/)).
- The Apps SDK is built on MCP. Lessons from the 2023 plugins launch led OpenAI to let brands own and steer their UI inside ChatGPT ([DevDay 2025](/podcasts/latent-space/2025/10/devday-2025-apps-sdk-agent-kit-mcp-codex-and-why-prompting-is-more-imp/)).
- The visual Agent Builder was started less than two months before launch, which the guests say Codex made possible. Wu thinks agent evals are maybe ten percent of the way there ([DevDay 2025](/podcasts/latent-space/2025/10/devday-2025-apps-sdk-agent-kit-mcp-codex-and-why-prompting-is-more-imp/)).
- Malte Ubl says Vercel's AI SDK stayed low level, so it needed no rewrite when developers moved from chatbots to agents. Version 6 beta adds a stable agent abstraction ([Ship AI recap](/podcasts/latent-space/2025/10/ship-ai-recap-agents-workflows-and-python-w-vercel-cto-malte-ubl/)).

### Prompt optimisation versus reinforcement learning

- The DevDay guests argue prompting has become more important, not less. OpenAI launched prompt optimisation with GPT-5 and prefers it to serving many fine-tuned snapshots ([DevDay 2025](/podcasts/latent-space/2025/10/devday-2025-apps-sdk-agent-kit-mcp-codex-and-why-prompting-is-more-imp/)).
- Kyle Corbitt describes OpenPipe's move from distilling GPT-4 to task-specific RL, as frontier price cuts eroded distillation. He now gives RL a 55-60% chance of being the right direction ([Why RL Won](/podcasts/latent-space/2025/10/why-rl-won-kyle-corbitt-openpipe-acq-coreweave/)).
- On one benchmark, Corbitt says GEPA prompt optimisation went from about 50% to 56% while RL reached about 96%. He calls realistic environments the main bottleneck ([Why RL Won](/podcasts/latent-space/2025/10/why-rl-won-kyle-corbitt-openpipe-acq-coreweave/)).
- He estimates “10 times as much AI inference that could exist than is existing right now” is stuck in proofs of concept for lack of reliability ([Why RL Won](/podcasts/latent-space/2025/10/why-rl-won-kyle-corbitt-openpipe-acq-coreweave/)).

### Durable workflows and narrow agents

- Ubl argues every transaction system has an explicit workflow abstraction “or someone made one ad hoc”. Vercel's open-source kit lets serverless code pause for days and await human approval ([Ship AI recap](/podcasts/latent-space/2025/10/ship-ai-recap-agents-workflows-and-python-w-vercel-cto-malte-ubl/)).
- He found internal agents by asking staff what they hate most about their jobs, which produced lead qualification, abuse-report and data analyst agents ([Ship AI recap](/podcasts/latent-space/2025/10/ship-ai-recap-agents-workflows-and-python-w-vercel-cto-malte-ubl/)).
- Huang says real human-in-the-loop workflows can run for weeks and involve real decisions, beyond simple tool approvals ([DevDay 2025](/podcasts/latent-space/2025/10/devday-2025-apps-sdk-agent-kit-mcp-codex-and-why-prompting-is-more-imp/)).

### Design and taste when code gets cheap

- Dylan Field argues that “the better code generation gets, the more design matters”, and that brand, taste and craft win as software creation explodes ([Figma](/podcasts/latent-space/2025/10/taste-is-your-moat-dylan-field-of-figma/)).
- Field doubts an agent could build Figma in the near term, and says products like Workday encode decades of edge cases that cannot simply be vibe-coded away ([Figma](/podcasts/latent-space/2025/10/taste-is-your-moat-dylan-field-of-figma/)).
- Ubl takes the other side of vibe coding: Vercel encourages all employees to contribute code and is building apps that stay secure even when developer and AI are not competent ([Ship AI recap](/podcasts/latent-space/2025/10/ship-ai-recap-agents-workflows-and-python-w-vercel-cto-malte-ubl/)).
