## Overview

August on Latent Space was a systems month. After a look back at Code Interpreter and Llama 2, guests went deep on how models are compiled for any device, how training is limited by memory and communication, and whether recurrent networks can beat attention on long context. Cursor's Aman Sanger made the case for rebuilding the code editor around AI.

## Main themes

### Llama 2, open models and the move beyond raw model size

- swyx calls Llama 2 the first commercially usable GPT-3.5 equivalent. Alessio Fanelli says it is not open source by the OSI definition but still “like $3 million of, like, flops donated to the community” ([Summer Roundup](/podcasts/latent-space/2023/08/ai-breakdown-summer-ai-technical-roundup-a-latent-space-x-ai-breakdown/)).
- swyx sees Code Interpreter as a separate model whose main gain is more inference time on hard problems. Alessio argues a nice UI wrapper around an OpenAI model is no longer enough ([Summer Roundup](/podcasts/latent-space/2023/08/ai-breakdown-summer-ai-technical-roundup-a-latent-space-x-ai-breakdown/)).
- On whether GPT-4 got worse, Alessio says evals are among the hardest problems in the field. swyx notes Claude 2's 100K context and the lost-in-the-middle findings on long-context retrieval ([Summer Roundup](/podcasts/latent-space/2023/08/ai-breakdown-summer-ai-technical-roundup-a-latent-space-x-ai-breakdown/)).

### Running models anywhere

- Tianqi Chen argues that machine learning compilation lets one optimised pipeline deploy to CUDA, AMD, Apple M2, phones and browsers. TVM generates kernels where no vendor library exists ([MLC](/podcasts/latent-space/2023/08/llms-everywhere-running-70b-models-in-browsers-and-iphones-using-mlc-w/)).
- Chen walks through kernel fusion, memory planning, loop transformations and int4 weight quantisation. WebLLM runs a 70B Llama 2 in the browser on a machine with about 50 GB of RAM ([MLC](/podcasts/latent-space/2023/08/llms-everywhere-running-70b-models-in-browsers-and-iphones-using-mlc-w/)).
- Chen hopes for personal local models working with larger cloud models rather than a few big players ([MLC](/podcasts/latent-space/2023/08/llms-everywhere-running-70b-models-in-browsers-and-iphones-using-mlc-w/)).

### The maths of training at scale

- Quentin Anthony explains compute as roughly 6 times parameters times tokens, and says an A100 delivering under 115 TFLOPS signals a software problem ([Training Maths](/podcasts/latent-space/2023/08/the-mathematics-of-training-llms-with-quentin-anthony-of-eleuther-ai/)).
- He argues memory, especially optimiser state, is the real limit: vanilla Adam needs 12 bytes per parameter, so 8-bit optimisers save more than quantising weights ([Training Maths](/podcasts/latent-space/2023/08/the-mathematics-of-training-llms-with-quentin-anthony-of-eleuther-ai/)).
- Anthony says “three-D parallel gives you the most control and also the most ways to go wrong”, which is why many teams now use pure ZeRO sharding ([Training Maths](/podcasts/latent-space/2023/08/the-mathematics-of-training-llms-with-quentin-anthony-of-eleuther-ai/)).

### An AI-first code editor

- Aman Sanger argues that if models write 90-95% of code, autocomplete cannot stay the main interface. Anysphere forked VS Code partly because of platform risk from competing with the platform owner ([Cursor](/podcasts/latent-space/2023/08/cursor-so-the-ai-first-code-editor-with-aman-sanger-of-anysphere/)).
- Early GPT-4 scored 85% on HumanEval against 30% for the best open model. Because models struggle with diffs, Cursor has GPT-4 draft changes and GPT-3.5 heal them ([Cursor](/podcasts/latent-space/2023/08/cursor-so-the-ai-first-code-editor-with-aman-sanger-of-anysphere/)).
- Sanger sees small, auditable Code Interpreter-style steps as the workable agent pattern, and notes Llama 2 suits prompt-heavy tasks such as re-ranking ([Cursor](/podcasts/latent-space/2023/08/cursor-so-the-ai-first-code-editor-with-aman-sanger-of-anysphere/)).

### RWKV and long context

- Eugene Cheah argues quadratic attention makes very long contexts impractical. His UI-testing product hit this on e-commerce pages that could exceed a million tokens ([RWKV](/podcasts/latent-space/2023/08/rwkv-reinventing-rnns-for-the-transformer-era-with-eugene-cheah-of-uil/)).
- RWKV is an attention-free recurrent network that trains in parallel. EleutherAI and Stability donated A100s for 7B and 14B models, which Cheah says match GPT-NeoX on the same data ([RWKV](/podcasts/latent-space/2023/08/rwkv-reinventing-rnns-for-the-transformer-era-with-eugene-cheah-of-uil/)).
- Cheah admits RWKV degrades beyond its 8K-16K training context; the community is working to extend its non-lossy memory ([RWKV](/podcasts/latent-space/2023/08/rwkv-reinventing-rnns-for-the-transformer-era-with-eugene-cheah-of-uil/)).
