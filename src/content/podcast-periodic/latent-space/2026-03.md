## Overview

March on Latent Space asked what agents need beyond the model: a computer of their own, an identity, and infrastructure that can keep up with them. Cursor, Anthropic, Box and Dreamer covered the product side, while Turbopuffer and NVIDIA covered search and inference. Two episodes stepped outside agents, on AI for materials discovery and Mistral's model strategy.

## Main themes

### Agents get their own computer

- Cursor's Jonas and Sam call cloud agents the company's third era, after tab completion and local agents. Each agent gets a VM, tests its work end to end and returns a video, which Jonas sees as the new entry point for code review ([Cursor](/podcasts/latent-space/2026/03/cursor-s-third-era-cloud-agents/)).
- The volume is already a problem. One guest says “we've broken our GitHub actions recently because we have so many agents”, and Jonas expects spending per developer to reach thousands of dollars a month ([Cursor](/podcasts/latent-space/2026/03/cursor-s-third-era-cloud-agents/)).
- Felix Rieseberg describes Claude Cowork as Claude Code in a local VM and says “it is quite powerful to give Claude its own computer.” He argues Silicon Valley undervalues the local machine ([Claude Cowork](/podcasts/latent-space/2026/03/why-anthropic-thinks-ai-should-have-its-own-computer-felix-rieseberg-o/)).
- Rieseberg says non-technical users had started using Claude Code for expenses and knowledge bases, which shaped Cowork ([Claude Cowork](/podcasts/latent-space/2026/03/why-anthropic-thinks-ai-should-have-its-own-computer-felix-rieseberg-o/)).

### Agents for knowledge work: identity and platforms

- Aaron Levie argues knowledge work lacks the conditions that let AI coding take off. He says “We've hit the easy button with AI, which is the agent just is you”, while autonomous agents need their own identity and their creators carry the liability ([Box](/podcasts/latent-space/2026/03/every-agent-needs-a-box-aaron-levie-box/)).
- Levie expects prompt-injection security incidents and a multi-year effort in which companies adapt workflows to agents. swyx frames 2026 as the year of knowledge work agents ([Box](/podcasts/latent-space/2026/03/every-agent-needs-a-box-aaron-levie-box/)).
- David Singleton presents Dreamer as a platform like Android, with a Sidekick agent acting as a kernel that mediates every interaction between agents, tools and personal data. He built a conference app in about 25 minutes ([Dreamer](/podcasts/latent-space/2026/03/dreamer-the-personal-agent-os-david-singleton/)).
- Both Levie and Rieseberg raised the effect of AI on jobs, with Rieseberg saying Anthropic is deeply worried about entry-level roles ([Box](/podcasts/latent-space/2026/03/every-agent-needs-a-box-aaron-levie-box/), [Claude Cowork](/podcasts/latent-space/2026/03/why-anthropic-thinks-ai-should-have-its-own-computer-felix-rieseberg-o/)).

### Search and inference rebuilt for agents

- Simon Hørup Eskildsen says agents now fire many parallel queries per round trip instead of one retrieval up front, so Turbopuffer is cutting query prices about fivefold. Cursor moved to Turbopuffer and cut costs by 95% ([Turbopuffer](/podcasts/latent-space/2026/03/retrieval-after-rag-hybrid-search-agents-and-database-design-simon-h-r/)).
- Kyle Kranen describes NVIDIA Dynamo, which separates prefill and decode across a data centre, and says agent harnesses add structure that inference can exploit for cache hits ([NVIDIA](/podcasts/latent-space/2026/03/nvidia-s-ai-engineers-agent-inference-at-planetary-scale-and-speed-of/)).
- Nader Khalil says agents should get only two of three powers: reading files, reaching the internet or running code. NVIDIA is building CLIs for business apps, an idea Dreamer shares with its own SDK and CLI ([NVIDIA](/podcasts/latent-space/2026/03/nvidia-s-ai-engineers-agent-inference-at-planetary-scale-and-speed-of/), [Dreamer](/podcasts/latent-space/2026/03/dreamer-the-personal-agent-os-david-singleton/)).

### AI for science and specialised models

- Heather Kulik explains why materials have no AlphaFold: sparse, low-fidelity data, no CASP-style benchmark and far more building blocks than proteins ([Materials](/podcasts/latent-space/2026/03/why-there-is-no-alphafold-for-materials-ai-for-materials-discovery-wit/)).
- Her group's active learning work on CO2 capture optimises seven objectives at once, and an AI screen found a plastic about four times tougher ([Materials](/podcasts/latent-space/2026/03/why-there-is-no-alphafold-for-materials-ai-for-materials-discovery-wit/)).
- Guillaume Lample argues for small, efficient open-weight models that customers fine-tune on their own data, shown in Voxtral TTS, the Forge platform and Leanstral ([Mistral](/podcasts/latent-space/2026/03/mistral-voxtral-tts-forge-leanstral-what-s-next-for-mistral-4-w-pavan/)).
