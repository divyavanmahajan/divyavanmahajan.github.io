## Thesis

Ksenia Se argues that the open-source coding agent OpenCode is becoming a company that buys, packages and resells model access. That puts it in competition with OpenRouter, the gateway Stripe has agreed to buy for a reported $8 billion. Her broader point is that a large enough application can pool its users' demand, negotiate with suppliers directly and decide which models developers see. Model choice then becomes procurement, settled before anyone opens the model menu.

## Key points

- **Four layers per request.** Se traces a request from a model lab (such as Z.ai, Anthropic or OpenAI) through inference providers and a gateway like OpenRouter to an agent harness like OpenCode. Four companies may take part before any code changes.
- **OpenCode sells inference.** Zen gives pay-as-you-go access to model and provider combinations tested for coding. Go is a $10 monthly subscription whose limits OpenCode values at up to $60 a month at public API prices. Both work through standard endpoints, so other agents can use them. OpenRouter charges 5.5% on credit purchases.
- **Comparable traffic.** CEO Jay V said OpenCode was processing about 7 trillion tokens a day; OpenRouter reported more than 10 trillion. Se cautions that the figures were collected differently.
- **Renting GPUs next.** Co-founder Dax Raad claimed OpenCode is the top buyer of some models and estimated a first GPU batch would need about $40 million upfront. Se calls OpenRouter a horizontal aggregator across many applications and OpenCode a vertical one inside coding.
- **Launch partner role.** During the Ox Alpha preview, Z.ai's GLM-5.3-Flash was credited with about 45 trillion tokens, 500,000 users and more than 13 million sessions on OpenCode. Z.ai paid for the inference, and OpenCode and OpenRouter provided distribution.
- **Who could buy it.** Because the code is MIT-licensed, a buyer would be paying for Anomaly, the brand and the community's trust. Se names Stripe with OpenRouter, NVIDIA with Hugging Face, and Cloudflare as logical buyers. She warns that a model lab owning OpenCode would undermine its neutrality.
