## Thesis

Ksenia Se recorded this conversation at Microsoft Build with Eric Boyd, the Microsoft corporate vice president who leads engineering for the AI platform. Boyd argues that whether we hand work to AI depends on the scenario. Low-risk tasks are being delegated already, and some high-risk ones, such as major medical procedures or launching nuclear missiles, may never be. He thinks progress depends on guardrails and enterprise controls more than on model capability. He prefers to talk about useful tools rather than AGI.

## Key points

- **Agents take over drudge work.** Boyd describes an internal GitHub agent demo that upgraded a code base from Java 8 to Java 17, working through broken APIs and dependencies the way a person would. He also cites Nuance DAX, which listens to doctor-patient conversations and writes the medical record.
- **A higher bar than humans.** Microsoft works on trust through training data, post-training and the Azure Content Safety system. Boyd says it remains an open societal question whether AI that makes mistakes at human rates is acceptable, and for now the answer is often no.
- **From copilot to guardrailed agents.** Copilot was the right metaphor for the first phase. With agents, companies set thresholds: one two-sided marketplace lets an agent issue refunds up to a set amount to settle disputes. The GitHub agent can write and test code but cannot check it in, deploy it or send it outside its environment.
- **The agentic web.** Boyd compares the agentic web to the dot-com era. Microsoft's NLWeb makes it simpler to add agents to websites, and he expects a site without an AI agent to seem outdated soon.
- **Developers and fluency.** His team uses GitHub Copilot heavily. He agrees with companies that let candidates use AI in interviews, comparing AI tools to calculators. He estimates two to five years before agents are common in professional life, and says existing models alone would take at least five years to absorb.
- **Enterprise worries.** Customers ask about governance and data leaks. Boyd points to Entra ID integration, which gives each agent an identity with centrally managed access.
