## Thesis

Recorded live at Microsoft Build with the No Priors hosts, this conversation has Satya Nadella arguing that AI should be an ecosystem play rather than one model or platform: a platform is judged by how much value it creates for others versus what it captures. His recipe for any company is a clean small model, an open multi-model harness, rich context and, above all, private evals that let it switch models and keep improving.

## Key points

- **MAI models and the "cognitive core".** Nadella says Microsoft's MAI models start from a clean pre-training lineage so that a small 5B model can be hill-climbed into a specialist. In one keynote demo, traces from GPT-5.5 were used to train a 5B reasoning model that scored higher.
- **Private evals as IP.** His acid test: if you can swap model A for model B against your private eval and still climb, you are in control. He suggests agent traces that build a "company veteran agent" could one day go on the balance sheet.
- **Harnesses.** Microsoft uses the GitHub harness across its products and in Foundry, and claims its MDASH security harness found vulnerabilities that Mythos missed.
- **SaaS unbundling.** Nadella expects data models and business logic (a general ledger, Power BI semantic models) to stay valuable while the UI layer is re-litigated. Work IQ exposes M365 data as a database for agents, and GitHub Copilot now needs a consumption meter alongside per-user pricing.
- **Meta work.** The Azure networking team built an agent called Miles to run fibre operations and asked for tokens instead of headcount. Microsoft says it built more Azure capacity in 15 months than in its first 15 years.
- **Community permission.** Nadella says data centre build-outs must show real local benefits (energy prices, water, jobs, tax base), and that education, citing Alpha School, is ripe for a new kind of university.
