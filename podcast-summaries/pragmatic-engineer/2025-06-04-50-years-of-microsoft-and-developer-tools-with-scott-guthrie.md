## Thesis

Scott Guthrie, Microsoft's executive vice president for cloud and AI, tells Gergely Orosz that Microsoft began as a developer tools company and still is one, because platforms only succeed through the applications developers build on them. He argues that every productivity jump, from Visual Basic to IntelliSense to AI copilots, met resistance but ended up creating more and better-paid developer jobs.

## Key points

- **Tools sold the platform.** Guthrie traces the company back to Microsoft BASIC for the Altair and says tools like QuickBASIC, Microsoft C and MFC helped Windows win. He draws the same line to Azure today, noting ChatGPT runs on it with an infrastructure team of 12 people.
- **.NET closed a gap.** Guthrie says .NET and its common language runtime were built to fill the space between Visual Basic and C++. He wrote the first ASP.NET prototype over Christmas 1997 with Mark Anders, and credits Anders Hejlsberg (Turbo Pascal, C#, TypeScript) for C#'s design.
- **Windows Phone lessons.** Orosz calls it the best developer experience he has used. Guthrie blames its failure on arriving after Android and on tooling that only ran on Windows when many developers used Macs.
- **Fixing Azure.** After Satya Nadella asked him to join Azure in 2011, Guthrie ran an offsite where leaders tried to build an app on prepaid cards and many could not even sign up. A punch list led to a 2012 relaunch with Linux support and a hybrid-cloud focus that took Azure from about seventh to second.
- **Three bold bets in 2014.** In a meeting of about an hour and a half, Guthrie's group decided on a free Visual Studio Community edition, open-sourcing .NET cross-platform, and VS Code. He says VS Code built the credibility that led to the GitHub acquisition.
- **Agents as coworkers.** Guthrie is most excited about assigning GitHub issues to Copilot and getting work back after 10 to 20 minutes, and about AI help for operations and SRE tasks.
