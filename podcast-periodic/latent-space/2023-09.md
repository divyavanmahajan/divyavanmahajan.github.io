## Overview

September on Latent Space was about the tooling layer between models and products. Harrison Chase and Raza Habib described how LLM apps get built, debugged and evaluated, while Chris Lattner argued the software underneath AI needs rebuilding. Youssef Rizk of Wondercraft took on the question of whether apps built on third-party APIs can be defensible.

## Main themes

### LangChain, chains and agents

- Harrison Chase defines the project plainly: “basically LangChain's a framework for building context-aware reasoning applications.” He argues its value is optionality across models and vector stores plus ready-made chains ([LangChain](/podcasts/latent-space/2023/09/the-point-of-langchain-with-harrison-chase-of-langchain/)).
- Chase separates fixed-sequence chains from agents, where the LLM picks the steps. Agents handle the long tail of edge cases, so he recommends starting with a chain and adding reasoning only where needed ([LangChain](/podcasts/latent-space/2023/09/the-point-of-langchain-with-harrison-chase-of-langchain/)).
- A team of 10 to 11 people faces 2,000 to 3,000 open GitHub issues. Chase answers critics with revamped docs and the LangChain Expression Language ([LangChain](/podcasts/latent-space/2023/09/the-point-of-langchain-with-harrison-chase-of-langchain/)).

### Evaluation and foundation model ops

- Chase describes LangSmith as a control centre for debugging, logging, testing and evaluation that logs every run after three environment variables are set, and can be used without LangChain ([LangChain](/podcasts/latent-space/2023/09/the-point-of-langchain-with-harrison-chase-of-langchain/)).
- Raza Habib argues prompts are now source code and need versioning and evaluation. He prefers the term foundation model ops to LLM Ops because models will soon handle images too ([Humanloop](/podcasts/latent-space/2023/09/building-the-foundation-model-ops-platform-with-raza-habib-of-humanloo/)).
- Habib separates evaluation during development, production monitoring and regression tests, and says user feedback is the only real ground truth for subjective tasks ([Humanloop](/podcasts/latent-space/2023/09/building-the-foundation-model-ops-platform-with-raza-habib-of-humanloo/)).
- He thinks MLOps companies will struggle to pivot into the space, and says his tooling gets stickier as customers scale ([Humanloop](/podcasts/latent-space/2023/09/building-the-foundation-model-ops-platform-with-raza-habib-of-humanloo/)).

### Rebuilding AI infrastructure

- Chris Lattner says TensorFlow and PyTorch rely on thousands of hand-written kernels, so new hardware must re-implement them. He adds “There's no LLVM for machine learning” ([Modular](/podcasts/latent-space/2023/09/doing-it-the-hard-way-making-the-ai-engine-and-language-of-the-future/)).
- Lattner argues compilers scale better than humans because they can fuse kernels in many ways. Modular started on CPUs, where much inference still runs, with GPUs to follow ([Modular](/podcasts/latent-space/2023/09/doing-it-the-hard-way-making-the-ai-engine-and-language-of-the-future/)).
- Mojo began because the team disliked writing low-level MLIR by hand. Lattner positions Modular as neutral: no hardware, no cloud and no LLM ([Modular](/podcasts/latent-space/2023/09/doing-it-the-hard-way-making-the-ai-engine-and-language-of-the-future/)).

### AI content and application moats

- Asked whether Wondercraft is a thin wrapper around ElevenLabs, Youssef Rizk argues moats come from serving a specific user well, since general APIs are not built for every use case ([Wondercraft](/podcasts/latent-space/2023/09/heralds-of-the-ai-content-flippening-with-youssef-rizk-of-wondercraft/)).
- Wondercraft announced AI dubbing checked by professional translators. Rizk says AI-generated shows should disclose it and plans to watermark once a standard exists ([Wondercraft](/podcasts/latent-space/2023/09/heralds-of-the-ai-content-flippening-with-youssef-rizk-of-wondercraft/)).
- OpenAI came up across three episodes. Chase estimates it holds over 90% of usage, and Habib thinks GPT-4 changed rather than got worse ([LangChain](/podcasts/latent-space/2023/09/the-point-of-langchain-with-harrison-chase-of-langchain/), [Humanloop](/podcasts/latent-space/2023/09/building-the-foundation-model-ops-platform-with-raza-habib-of-humanloo/)).
