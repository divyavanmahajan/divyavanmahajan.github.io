## Overview

November on Latent Space was dominated by coding agents: Google's Jules, GitHub's Agent HQ and a services firm that pays engineers for AI-boosted output. Claude Code came up in three of the five episodes. Deedy Das of Menlo Ventures discussed where AI moats come from, and Fei-Fei Li and Justin Johnson closed the month with spatial intelligence.

## Main themes

### Coding agents as platforms

- Jared Palmer describes GitHub's Agent HQ as a home for many agents: Copilot sits alongside third-party harnesses “like Cloud Code and, and Codex and Cognition” ([Agent HQ](/podcasts/latent-space/2025/11/inside-github-s-ai-revolution-jared-palmer-reveals-agent-hq-the-future/)).
- Palmer wants AI added at existing touch points such as merge conflicts and failing Actions, plus custom agents that can use MCP ([Agent HQ](/podcasts/latent-space/2025/11/inside-github-s-ai-revolution-jared-palmer-reveals-agent-hq-the-future/)).
- Jed Borovik says Jules runs in its own VM for hours or days, with an API, a CLI and Agent HQ integration. One user auto-merges its pull requests through a GitHub Action ([Jules](/podcasts/latent-space/2025/11/aie-code-preview-inside-google-labs-building-the-gemini-coding-agent-j/)).

### Reliability and simpler scaffolds

- Palmer says moving from 90% to 99% success gets steeper, and most teams overrate their product's quality. The hosts call repo setup the top pain point for coding agents ([Agent HQ](/podcasts/latent-space/2025/11/inside-github-s-ai-revolution-jared-palmer-reveals-agent-hq-the-future/)).
- Borovik observes that scaffolds “get simpler and simpler over time as the models get better”, and that agentic search is replacing embedding-based RAG ([Jules](/podcasts/latent-space/2025/11/aie-code-preview-inside-google-labs-building-the-gemini-coding-agent-j/)).
- Borovik cites Jevons paradox to argue demand for software is elastic, so AI coding will raise demand for engineers ([Jules](/podcasts/latent-space/2025/11/aie-code-preview-inside-google-labs-building-the-gemini-coding-agent-j/)).

### Paying for AI-boosted engineering

- Alex Lieberman and Arman Hezarkhani of Tenex pay engineers by story points rather than hours, arguing hourly billing punishes those who use AI to work ten times faster ([Tenex](/podcasts/latent-space/2025/11/10x-ai-engineers-with-1m-salaries-alex-lieberman-arman-hezarkhani-tene/)).
- They control gaming through hiring and through strategists paid on net revenue retention. Hezarkhani expects several engineers to earn over $1 million next year ([Tenex](/podcasts/latent-space/2025/11/10x-ai-engineers-with-1m-salaries-alex-lieberman-arman-hezarkhani-tene/)).
- Hezarkhani prefers TypeScript end to end because compiler errors let agents such as Claude Code correct themselves and keep working autonomously for longer ([Tenex](/podcasts/latent-space/2025/11/10x-ai-engineers-with-1m-salaries-alex-lieberman-arman-hezarkhani-tene/)).
- Das takes a sceptical view of vibe coding, comparing coding agents to a slot machine, while swyx says fast agents can still help engineers read code ([AI Moats](/podcasts/latent-space/2025/11/anthropic-glean-openrouter-how-ai-moats-are-built-with-deedy-das-of-me/)).

### Where AI moats come from

- Das argues durable advantage comes from doing the hardest work in the stack. Of Glean he says the advantage is simply that it did the hard search work before LLMs arrived ([AI Moats](/podcasts/latent-space/2025/11/anthropic-glean-openrouter-how-ai-moats-are-built-with-deedy-das-of-me/)).
- He thinks the model layer is more defensible than the app layer, since few apps have a thick enough layer on top of the model ([AI Moats](/podcasts/latent-space/2025/11/anthropic-glean-openrouter-how-ai-moats-are-built-with-deedy-das-of-me/)).
- Das calls Anthropic the fastest-growing software company ever and singles out Claude Code. The $100 million Anthology Fund has backed about 40 companies, including OpenRouter ([AI Moats](/podcasts/latent-space/2025/11/anthropic-glean-openrouter-how-ai-moats-are-built-with-deedy-das-of-me/)).

### Spatial intelligence and world models

- Fei-Fei Li and Justin Johnson argue spatial intelligence is the next frontier after language and complements it rather than replacing it ([World Labs](/podcasts/latent-space/2025/11/after-llms-spatial-intelligence-and-world-models-fei-fei-li-justin-joh/)).
- Marble generates editable 3D worlds as Gaussian splats that render in real time on phones. The founders target gaming, film, design and simulation data for robot training ([World Labs](/podcasts/latent-space/2025/11/after-llms-spatial-intelligence-and-world-models-fei-fei-li-justin-joh/)).
