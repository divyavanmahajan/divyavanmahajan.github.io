## Overview

September on Latent Space had two episodes, both about building agents that keep up with fast-improving models. Lance Martin of LangChain mapped the techniques of context engineering, and Quinn Slack and Thorsten Ball explained why Sourcegraph keeps its Amp coding agent minimal. Both kept returning to Claude Code, MCP and the bitter lesson.

## Main themes

### Context engineering for agents

- Lance Martin defines context engineering as “the challenge of feeding an LM just the right context for the next step”, and calls prompt engineering a subset of it ([Context Engineering](/podcasts/latent-space/2025/09/context-engineering-for-agents-lance-martin-langchain/)).
- Tool calls flood the context window: his naive deep researcher used 500,000 tokens per run. He groups the fixes as offloading, retrieval, reducing context, isolation and caching ([Context Engineering](/podcasts/latent-space/2025/09/context-engineering-for-agents-lance-martin-langchain/)).
- Martin says parallel sub-agents suit read-only research followed by one write step, as in Anthropic's research system, but can make conflicting decisions in coding ([Context Engineering](/podcasts/latent-space/2025/09/context-engineering-for-agents-lance-martin-langchain/)).
- The Amp guests are wary of conversation compaction because it loses signal, and they reject large MCP tool lists that waste tokens ([Amp](/podcasts/latent-space/2025/09/amp-the-emperor-has-no-clothes/)).

### Simple retrieval and Claude Code as reference point

- Martin notes that Claude Code does no indexing and relies on grep-style agentic search. In his test on LangGraph docs, an llms.txt with good descriptions beat vector search and context stuffing ([Context Engineering](/podcasts/latent-space/2025/09/context-engineering-for-agents-lance-martin-langchain/)).
- He calls CLAUDE.md files the simplest form of memory and argues prompts for using an MCP server should live in the server itself ([Context Engineering](/podcasts/latent-space/2025/09/context-engineering-for-agents-lance-martin-langchain/)).
- The Amp guests argue that Claude Code, Codex and Cursor are overfit to current model capabilities, and say Anthropic appears to train its models towards using memory ([Amp](/podcasts/latent-space/2025/09/amp-the-emperor-has-no-clothes/)).

### Building for the next model

- Martin rebuilt Open Deep Research twice to remove 2024 workflow assumptions. He prefers low-level orchestration such as LangGraph over opaque agent abstractions ([Context Engineering](/podcasts/latent-space/2025/09/context-engineering-for-agents-lance-martin-langchain/)).
- Quinn Slack and Thorsten Ball say no coding tool has held developers for more than six to twelve months, so Amp must stay able to rebuild when the next model lands ([Amp](/podcasts/latent-space/2025/09/amp-the-emperor-has-no-clothes/)).
- Amp drops model pickers, bring-your-own-key and custom sub-agents, and wants scaffolding that falls away as models improve ([Amp](/podcasts/latent-space/2025/09/amp-the-emperor-has-no-clothes/)).
- Ball describes eight engineers pushing to main 15 times a day with no formal evals. He says Amp writes “80 to 90% of our code base”, and usage grows more than 50% a month ([Amp](/podcasts/latent-space/2025/09/amp-the-emperor-has-no-clothes/)).
