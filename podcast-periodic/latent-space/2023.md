## Overview

Latent Space's first year tracked OpenAI's platform from the ChatGPT API to plugins, function calling, Code Interpreter and DevDay, often in live emergency pods. Open models were the counterweight, from the No Moat memo to Llama 2. The middle of the stack had its own debates: RAG versus fine-tuning, evals, and why agents did not work yet. By October the show framed it all as the rise of the AI engineer.

## Main themes

### OpenAI's platform, launch by launch

- Logan Kilpatrick says “ChatGPT in its current form is definitely a research preview” while the GPT-3.5 model under it is not, and argues lasting products need proprietary data ([ChatGPT, GPT4 hype](/podcasts/latent-space/2023/02/chatgpt-gpt4-hype-and-building-llm-native-products-with-logan-kilpatri/)).
- On plugin launch day swyx called ChatGPT's code execution a new compute platform ([ChatGPT's App Store Moment](/podcasts/latent-space/2023/03/emergency-pod-chatgpt-s-app-store-moment-w-openai-s-logan-kilpatrick-l/)); by July a panel rated Code Interpreter the most capable agent available ([Code Interpreter == GPT 4.5](/podcasts/latent-space/2023/07/code-interpreter-gpt-4-5-w-simon-willison-alex-volkov-aravind-srinivas/)).
- Simon Willison warned that prompt injection remained unsolved ([Functions API](/podcasts/latent-space/2023/06/emergency-pod-openai-s-new-functions-api-75-price-drop-4x-context-leng/)).
- DevDay's GPT-4 Turbo, Assistants API and GPTs were judged powerful but under-documented, with real pressure on startups ([DevDay Recap](/podcasts/latent-space/2023/11/agi-is-being-achieved-incrementally-devday-recap-cleaned-audio/)).

### Open models catch up

- Willison and the hosts debated whether LLaMA and LoRA fine-tunes erode the lead of Google and OpenAI ([No Moat](/podcasts/latent-space/2023/05/no-moat-closed-ai-gets-its-open-source-wakeup-call-ft-simon-willison/)).
- Mike Conover argued cheap instruction tuning on open data matters more than owning a foundation model ([Dolly](/podcasts/latent-space/2023/04/mapping-the-future-of-truly-open-models-and-training-dolly-for-30-with/)); MosaicML made the same case with MPT-7B ([MPT-7B](/podcasts/latent-space/2023/05/mpt-7b-and-the-beginning-of-context-infinity-with-jonathan-frankle-and/)).
- Willison said “Meta kept their promise of doing a version of Llama that is use- usable for commercial purposes” ([Llama 2](/podcasts/latent-space/2023/07/llama-2-the-new-open-llm-sota-ft-nathan-lambert-matt-bornstein-anton-t/)). Phind later claimed fine-tuned open models could match GPT-4 for programmers ([Phind](/podcasts/latent-space/2023/11/beating-gpt-4-with-open-source-llms-with-michael-royzen-of-phind/)).

### RAG, fine-tuning and the data underneath

- Harrison Chase defended LangChain's retrieval abstractions ([LangChain](/podcasts/latent-space/2023/09/the-point-of-langchain-with-harrison-chase-of-langchain/)); Jerry Liu called RAG a good, easy hack that beats fine-tuning for now ([RAG Is A Hack](/podcasts/latent-space/2023/10/rag-is-a-hack-with-jerry-liu-from-llamaindex/)).
- Jeremy Howard argued the pretrain/fine-tune split is wrong and only continued pre-training remains ([End of Finetuning](/podcasts/latent-space/2023/10/the-end-of-finetuning-with-jeremy-howard-of-fast-ai/)); Wing Lian wants fine-tuning to be config switches ([Axolotl](/podcasts/latent-space/2023/12/the-busy-person-s-intro-to-finetuning-open-source-ai-wing-lian-axolotl/)).
- Synthetic data ran from TinyStories ([Tiny Model Revolution](/podcasts/latent-space/2023/07/cognitive-revolution-the-tiny-model-revolution-with-ronen-eldan-and-yu/)) to almost every NeurIPS conversation ([Top Startups](/podcasts/latent-space/2023/12/neurips-2023-recap-top-startups/)).

### Agents, coding tools and the AI engineer

- Sharif Shameem called browser agents an engineering problem ([AI Founder Gene](/podcasts/latent-space/2023/05/the-ai-founder-gene-being-early-building-fast-and-believing-in-greatne/)); Kanjun Qiu blamed weak reasoning and leaky abstractions for unreliable agents ([Imbue](/podcasts/latent-space/2023/10/why-ai-agents-don-t-work-yet-with-kanjun-qiu-of-imbue/)).
- Aman Sanger says “you need to own the full IDE and completely redesign the flow of producing, producing software” ([Cursor](/podcasts/latent-space/2023/08/cursor-so-the-ai-first-code-editor-with-aman-sanger-of-anysphere/)); Sourcegraph bet on context quality over agents ([Normsky](/podcasts/latent-space/2023/12/the-normsky-architecture-for-ai-coding-agents-with-beyang-liu-steve-ye/)).
- swyx argued foundation models let software engineers ship AI without ML teams ([Software 3.0](/podcasts/latent-space/2023/10/aie-summit-preview-1-swyx-on-software-3-0-and-the-rise-of-the-ai-engin/)).

### Evals, UX and compute

- Benchmarks saturate and suffer contamination ([Benchmarks 101](/podcasts/latent-space/2023/04/ai-fundamentals-benchmarks-101/)); Replit trusts vibes over HumanEval ([Replit](/podcasts/latent-space/2023/05/training-a-sota-code-llm-in-1-week-and-quantifying-the-vibes-with-reza/)).
- Linus Lee sees AI UX as very early ([Notion AI](/podcasts/latent-space/2023/06/building-the-ai-ux-scenius-with-linus-lee-of-notion-ai/)); Raza Habib treats prompts as source code ([Humanloop](/podcasts/latent-space/2023/09/building-the-foundation-model-ops-platform-with-raza-habib-of-humanloo/)).
- Dylan Patel expects compute to stay the bottleneck ([GPU Poors](/podcasts/latent-space/2023/11/the-state-of-silicon-and-the-gpu-poors-with-dylan-patel-of-semianalysi/)).
