## Overview

July on Latent Space had three long conversations, all about what sits around a model once agents do real work. Modal's CTO described a cloud rebuilt for agents as users, Poolside's co-founder explained how it builds and now releases models, and OpenAI's Akshay Nathan told how Codex turned into ChatGPT Work. The common thread was the agent harness: give the model a computer and keep the scaffolding thin.

## Main themes

### The agent harness and a computer to work in

- Akshay Nathan says Codex taught OpenAI that giving an agent a flexible computer environment lets it do powerful things well beyond software development ([Codex to ChatGPT Work](/podcasts/latent-space/2026/07/codex-from-0-to-10m-users-building-chatgpt-work-akshay-nathan-openai/)).
- Nathan explains that Codex and ChatGPT Work share one harness: “So the harness is the same. The harness is shared.” Codex mode shows Git state and diffs, while Work hides them and uses different sandbox defaults ([Codex to ChatGPT Work](/podcasts/latent-space/2026/07/codex-from-0-to-10m-users-building-chatgpt-work-akshay-nathan-openai/)).
- Eiso Kant argues that MCP and tool calls are a needless layer and that models should write code in a container instead. He predicts that within 12 months no system prompt will be stuffed with dozens of tools ([Poolside](/podcasts/latent-space/2026/07/inside-the-model-factory-eiso-kant-poolside-ai/)).

### Infrastructure built for agent experience

- Akshat Bubna says Modal has “changed our SDK team to think about agent experience” rather than developer experience, arguing the same benefits apply ([Modal](/podcasts/latent-space/2026/07/why-ai-infrastructure-must-evolve-for-agent-experience-akshat-bubna-mo/)).
- Modal Bench tests where agents fail with Modal. When agents hallucinate a feature the team sometimes builds it, and logs and metrics moved from the UI to the CLI ([Modal](/podcasts/latent-space/2026/07/why-ai-infrastructure-must-evolve-for-agent-experience-akshat-bubna-mo/)).
- Bubna says Modal built sandboxes in May 2023, long before agents took off. Sandboxes now support sidecars, so one sandbox can be a pod of containers, and RL rollouts can need 100,000 at once ([Modal](/podcasts/latent-space/2026/07/why-ai-infrastructure-must-evolve-for-agent-experience-akshat-bubna-mo/)).
- Modal owns no data centres. It pools capacity from 17 cloud providers, and Bubna sees elastic GPU scaling within a region and GPU snapshotting for faster cold starts as the hard production problems ([Modal](/podcasts/latent-space/2026/07/why-ai-infrastructure-must-evolve-for-agent-experience-akshat-bubna-mo/)).

### Poolside's model factory and open weights

- Kant says Poolside's view from early on was that “model building is ultimately 90% engineering”. Its factory optimises for the speed from a researcher's idea to an experimental result the team can trust ([Poolside](/podcasts/latent-space/2026/07/inside-the-model-factory-eiso-kant-poolside-ai/)).
- Laguna S has 118 billion total and 8 billion active parameters, took eight weeks from start of pre-training to launch and fits on a DGX Spark. Kant credits post-training for behaviour that counts for more than size ([Poolside](/podcasts/latent-space/2026/07/inside-the-model-factory-eiso-kant-poolside-ai/)).
- Poolside reopened the open-source question only this year. Kant prefers many foundation model companies to an oligopoly, values shared research over bare weights and opposes restricting open models at today's capability levels ([Poolside](/podcasts/latent-space/2026/07/inside-the-model-factory-eiso-kant-poolside-ai/)).

### Agents for knowledge work

- Nathan says ChatGPT Work came from non-developers at OpenAI, in finance and marketing, adopting Codex. He frames the rollout as a sequence from developers to knowledge work to everyone ([Codex to ChatGPT Work](/podcasts/latent-space/2026/07/codex-from-0-to-10m-users-building-chatgpt-work-akshay-nathan-openai/)).
- Artifacts such as spreadsheets, documents and hosted Sites were a big push for the launch. The product passed 10 million users and is only available to paid users for now ([Codex to ChatGPT Work](/podcasts/latent-space/2026/07/codex-from-0-to-10m-users-building-chatgpt-work-akshay-nathan-openai/)).
- With lines of code and token counts breaking down as proxies, Nathan suggests managers track the number and quality of at-bats ([Codex to ChatGPT Work](/podcasts/latent-space/2026/07/codex-from-0-to-10m-users-building-chatgpt-work-akshay-nathan-openai/)).
