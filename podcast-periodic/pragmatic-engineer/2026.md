## Overview

The Pragmatic Engineer spent 2026 asking how software engineering changes once agents write most of the code. Builders of Claude Code, Codex, Pi and OpenCode explained their tools, while veterans such as Grady Booch, Kent Beck and DHH gave context. Later the focus moved to verification and software factories. Episodes on S3, Uber, databases and resilience ran alongside.

## Main themes

### Coding agents become the default

- Mitchell Hashimoto pairs with agents so one side always reviews: “If I'm coding, I want an agent planning. If they're coding, I want to be reviewing.” ([Mitchell Hashimoto](/podcasts/pragmatic-engineer/2026/02/mitchell-hashimotos-new-way-of-writing-code/)).
- Boris Cherny says Claude Code writes “something like 80 percent of the code in Anthropic on average” ([Building Claude Code](/podcasts/pragmatic-engineer/2026/03/building-claude-code-with-boris-cherny/)).
- Peter Steinberger runs parallel agents as a one-person team ([Creator of Clawd](/podcasts/pragmatic-engineer/2026/01/the-creator-of-clawd-i-ship-code-i-dont-read/)); Mario Zechner and Armin Ronacher favour minimal harnesses ([Building Pi](/podcasts/pragmatic-engineer/2026/04/building-pi-and-what-makes-self-modifying-software-so-fascinating/)).
- Dax Raad argues agents make code cheaper but not good ideas ([Building OpenCode](/podcasts/pragmatic-engineer/2026/05/building-opencode-with-dax-raad/)), and Kent Beck says code is piling up faster than trust ([Kent Beck](/podcasts/pragmatic-engineer/2026/07/how-kent-beck-shapes-the-software-engineering-industry/)).

### Code review turns into verification

- Cherny says every Anthropic pull request is first reviewed by Claude Code in CI, with a human second pass ([Building Claude Code](/podcasts/pragmatic-engineer/2026/03/building-claude-code-with-boris-cherny/)); Tibo Sottiaux describes agents automating review inside OpenAI ([Building Codex](/podcasts/pragmatic-engineer/2026/09/building-codex-with-tibo-sottiaux/)).
- Charity Majors says unread AI code will ship, so verification discipline must grow ([Charity Majors](/podcasts/pragmatic-engineer/2026/08/stop-being-skeptical-about-ai-for-development-with-charity-majors/)).
- Dex Horthy traces the software factory idea back to 1968 ([Context engineering](/podcasts/pragmatic-engineer/2026/07/context-engineering-with-dex-horthy/)); Satya Nadella and Harjot Gill describe factories where verification and specifications replace line-by-line review ([Satya Nadella](/podcasts/pragmatic-engineer/2026/11/software-engineering-after-code-becomes-cheap-with-satya-nadella/), [Harjot Gill](/podcasts/pragmatic-engineer/2026/11/software-factories-and-code-reviews-with-harjot-gill/)).

### AI, jobs and junior engineers

- Grady Booch sees a third golden age, not an end, and says “The software delivery pipeline is far more complex than it should be.” ([Grady Booch](/podcasts/pragmatic-engineer/2026/02/the-third-golden-age-of-software-engineering-thanks-to-ai-with-grady-b/)).
- Steve Yegge says hand-coding is ending ([Steve Yegge](/podcasts/pragmatic-engineer/2026/03/from-ides-to-ai-agents-with-steve-yegge/)); DHH finds the most senior people gain most from agents ([DHH](/podcasts/pragmatic-engineer/2026/04/dhhs-new-way-of-writing-code/)).
- Addy Osmani warns against cognitive surrender ([Addy Osmani](/podcasts/pragmatic-engineer/2026/08/from-chrome-devtools-to-ai-engineering-with-addy-osmani/)); Titus Winters wants CS curricula to teach specification and verification ([Titus Winters](/podcasts/pragmatic-engineer/2026/10/software-engineering-at-google-cs-education-with-titus-winters/)).

### Distributed systems, scale and resilience

- Mai-Lan Tomsen Bukovec explains how S3 uses formal methods to guard consistency ([How AWS S3 is built](/podcasts/pragmatic-engineer/2026/01/how-aws-s3-is-built/)); Hillel Wayne says TLA+ pays off for distributed designs ([Hillel Wayne](/podcasts/pragmatic-engineer/2026/07/formal-methods-with-hillel-wayne/)).
- Martin Kleppmann explains how object stores reshaped data systems ([Martin Kleppmann](/podcasts/pragmatic-engineer/2026/04/designing-data-intensive-applications-with-martin-kleppmann/)).
- Thuan Pham recalls splitting Uber's monolith into microservices ([Scaling Uber](/podcasts/pragmatic-engineer/2026/04/scaling-uber-with-thuan-pham-ubers-first-cto/)); Sam Newman treats resilience as a matter of degree ([Sam Newman](/podcasts/pragmatic-engineer/2026/10/building-resilient-systems-with-sam-newman/)).

### Platforms that agents build on

- Robert Erez says platform teams set best practices and self-service while app teams keep ownership ([CI/CD](/podcasts/pragmatic-engineer/2026/06/ci-cd-with-robert-erez/)).
- Uday Kiran Medisetty says Uber's agent tooling works because it reuses a decade of developer platform investment ([Uber's AI infra](/podcasts/pragmatic-engineer/2026/10/ubers-ai-infra-from-the-inside/)); Maude Lemaire still verifies AI output by hand for foundational systems ([Maude Lemaire](/podcasts/pragmatic-engineer/2026/11/scaling-slack-and-github-with-maude-lemaire/)).
