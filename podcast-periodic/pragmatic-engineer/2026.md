## Overview

In 2026 The Pragmatic Engineer kept asking what software engineering becomes when agents write most of the code. Builders of Claude Code, Codex, OpenCode and Pi described their tools, and veterans such as Grady Booch, Kent Beck and DHH gave context. By autumn the focus had moved to verification and software factories, alongside classic episodes on S3, Uber and distributed databases.

## Main themes

### Working alongside coding agents

- Mitchell Hashimoto pairs his work with an agent's: “If I'm coding, I want an agent planning. If they're coding, I want to be reviewing.” ([Hashimoto](/podcasts/pragmatic-engineer/2026/02/mitchell-hashimotos-new-way-of-writing-code/)).
- Peter Steinberger argues one engineer running parallel agents can ship like a team if agents verify their own work ([Clawd](/podcasts/pragmatic-engineer/2026/01/the-creator-of-clawd-i-ship-code-i-dont-read/)); Boris Cherny says Claude Code writes about 80% of Anthropic's code ([Claude Code](/podcasts/pragmatic-engineer/2026/03/building-claude-code-with-boris-cherny/)).
- Mario Zechner and Armin Ronacher warn that agent speed is eroding code quality ([Pi](/podcasts/pragmatic-engineer/2026/04/building-pi-and-what-makes-self-modifying-software-so-fascinating/)); Peter Mattis says agents amplify domain experts ([Mattis](/podcasts/pragmatic-engineer/2026/09/distributed-databases-with-peter-mattis/)).

### Code review and verification

- Cherny says every Anthropic pull request is first reviewed by Claude Code in CI, with a human second pass ([Claude Code](/podcasts/pragmatic-engineer/2026/03/building-claude-code-with-boris-cherny/)); Tibo Sottiaux describes agents automating review inside OpenAI ([Codex](/podcasts/pragmatic-engineer/2026/09/building-codex-with-tibo-sottiaux/)).
- Charity Majors says code review means many things to many people, and that shipping unread AI code is a question of when, not if ([Majors](/podcasts/pragmatic-engineer/2026/08/stop-being-skeptical-about-ai-for-development-with-charity-majors/)).
- Titus Winters wants CS education to move towards specification, testing and verification ([Winters](/podcasts/pragmatic-engineer/2026/10/software-engineering-at-google-cs-education-with-titus-winters/)).

### Software factories

- Dex Horthy traces the term to a 1968 NATO conference and argues unread AI code degrades a codebase within months ([Horthy](/podcasts/pragmatic-engineer/2026/07/context-engineering-with-dex-horthy/)).
- Harjot Gill describes verification loops and release-level human review at CodeRabbit ([Gill](/podcasts/pragmatic-engineer/2026/11/software-factories-and-code-reviews-with-harjot-gill/)); Satya Nadella says specifications and verification become the core of the job ([Nadella](/podcasts/pragmatic-engineer/2026/11/software-engineering-after-code-becomes-cheap-with-satya-nadella/)).
- Katelyn Lesse describes agents rewriting Anthropic's API from Python to Rust while coordination stays human ([Lesse](/podcasts/pragmatic-engineer/2026/11/how-anthropic-builds-software-in-2026-with-katelyn-lesse/)).

### Jobs, careers and hiring

- Grady Booch calls this a third golden age and says “The software delivery pipeline is far more complex than it should be.” He expects job losses in messy infrastructure work ([Booch](/podcasts/pragmatic-engineer/2026/02/the-third-golden-age-of-software-engineering-thanks-to-ai-with-grady-b/)).
- DHH says the biggest agent gains at 37signals came from the most senior people ([DHH](/podcasts/pragmatic-engineer/2026/04/dhhs-new-way-of-writing-code/)); Steve Yegge thinks hand-coding is ending ([Yegge](/podcasts/pragmatic-engineer/2026/03/from-ides-to-ai-agents-with-steve-yegge/)).
- Navdeep Singh says coding interviews persist because nothing better scales ([NeetCode](/podcasts/pragmatic-engineer/2026/06/tech-interviews-with-neetcode/)); Will Larson wants managers back in technical decisions ([Larson](/podcasts/pragmatic-engineer/2026/10/the-revised-rules-of-engineering-management-with-will-larson/)).

### Systems at scale

- Mai-Lan Tomsen Bukovec explains how S3 uses formal methods to check its consistency model ([S3](/podcasts/pragmatic-engineer/2026/01/how-aws-s3-is-built/)); Martin Kleppmann and Hillel Wayne cover distributed systems and verification ([Kleppmann](/podcasts/pragmatic-engineer/2026/04/designing-data-intensive-applications-with-martin-kleppmann/), [Wayne](/podcasts/pragmatic-engineer/2026/07/formal-methods-with-hillel-wayne/)).
- Thuan Pham recalls Uber with 40 engineers and frequent crashes, and its move to microservices ([Pham](/podcasts/pragmatic-engineer/2026/04/scaling-uber-with-thuan-pham-ubers-first-cto/)); Uday Kiran Medisetty says Uber's AI tooling rests on its developer platform ([Uber AI](/podcasts/pragmatic-engineer/2026/10/ubers-ai-infra-from-the-inside/)).
- Kelsey Hightower argues “the hardest problem Google had, in my opinion, was what to build.” ([Hightower](/podcasts/pragmatic-engineer/2026/06/kubernetes-and-retiring-at-the-top-with-kelsey-hightower/)).
