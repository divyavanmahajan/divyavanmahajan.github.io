## Overview

November on The Pragmatic Engineer brought four senior voices to the same question: what AI coding tools are good for, and what still needs a human. Chris Lattner, Martin Fowler and Johannes Dahse all argued for review, tests and understanding over speed. Lattner's Mojo story and Netflix CTO Elizabeth Stone's account of live streaming added depth on compilers and engineering culture.

## Main themes

### AI coding tools need adult supervision

- Chris Lattner uses Cursor and estimates about 10% productivity for himself, much more for prototypes and PMs. He wants programmers to use AI as “a human assist, not a human replacement” and to keep reviewing the code ([Lattner](/podcasts/pragmatic-engineer/2025/11/from-swift-to-mojo-and-high-performance-ai-engineering-with-chris-latt/)).
- Elizabeth Stone says AI tools help Netflix most with prototyping, documentation, large migrations and anomaly response, supported by Gen AI champions. She calls them not a silver bullet ([Netflix](/podcasts/pragmatic-engineer/2025/11/netflixs-engineering-culture/)).
- Martin Fowler sees a non-trivial speedup, though not what advocates claim. He tells engineers to work in thin slices and treat each one as “a PR from a rather dodgy collaborator” ([Fowler](/podcasts/pragmatic-engineer/2025/11/how-ai-will-change-software-engineering-with-martin-fowler/)).

### Vibe coding and the learning loop

- Fowler defines vibe coding as never looking at the output. He finds it fine for explorations and throwaways, but not for long-lived code ([Fowler](/podcasts/pragmatic-engineer/2025/11/how-ai-will-change-software-engineering-with-martin-fowler/)).
- Citing Unmesh Joshi, he argues it removes the learning loop: “If you're not looking at the output, you're not learning.” His own LLM-generated SVG was too convoluted to tweak, only to discard ([Fowler](/podcasts/pragmatic-engineer/2025/11/how-ai-will-change-software-engineering-with-martin-fowler/)).
- Fowler frames the real shift as determinism to non-determinism, so engineers must think in tolerances and lean on refactoring and tests. Lattner also warns against vibe coding production systems ([Fowler](/podcasts/pragmatic-engineer/2025/11/how-ai-will-change-software-engineering-with-martin-fowler/), [Lattner](/podcasts/pragmatic-engineer/2025/11/from-swift-to-mojo-and-high-performance-ai-engineering-with-chris-latt/)).

### Verification is the new bottleneck for security

- Johannes Dahse of Sonar says writing code is no longer the hard part; verifying it is. He links poor-quality AI-generated code directly to security risk ([Code security](/podcasts/pragmatic-engineer/2025/11/code-security-for-software-engineers/)).
- He argues developers, not security teams, should own code security, because vulnerabilities are just bugs that only they can fix. Spaghetti code hides flaws and keeps the attacker window open longer ([Code security](/podcasts/pragmatic-engineer/2025/11/code-security-for-software-engineers/)).
- Sonar's report found about one issue per 1,000 lines, led by basics like log injection and SQL injection. Dahse compares AI reviewing AI-written code to students grading their own homework ([Code security](/podcasts/pragmatic-engineer/2025/11/code-security-for-software-engineers/)).

### Compilers and fragmented AI hardware

- Lattner says AI software today resembles the pre-GCC era, with every chip vendor building its own vertical stack. Modular's founding idea was an LLVM for AI that chipmakers can plug into ([Lattner](/podcasts/pragmatic-engineer/2025/11/from-swift-to-mojo-and-high-performance-ai-engineering-with-chris-latt/)).
- Modular has just over 140 people and supports seven architectures from three vendors. Mojo uses Python-family syntax and a simpler, predictable compiler, since Lattner says the sufficiently smart compiler never works ([Lattner](/podcasts/pragmatic-engineer/2025/11/from-swift-to-mojo-and-high-performance-ai-engineering-with-chris-latt/)).

### Netflix: responsibility over process

- Stone ties being unusually responsible to high talent density. Engineer-led teams built Netflix Live in 18 months, from a Chris Rock special to Paul vs. Tyson at 65 million concurrent streams ([Netflix](/podcasts/pragmatic-engineer/2025/11/netflixs-engineering-culture/)).
- Netflix adds light guardrails such as service tiers and quiet periods, then dials them back. It skips formal performance reviews and now hires early-career engineers after 25 years of senior-only hiring ([Netflix](/podcasts/pragmatic-engineer/2025/11/netflixs-engineering-culture/)).
