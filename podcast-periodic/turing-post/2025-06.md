## Overview

June on Turing Post had two conversations with Ksenia Se about where people still fit as AI agents take on more work. Toloka's Olga Megorskaya looked at it from the data side, with humans as experts and the benchmark for models. Microsoft's Eric Boyd looked at it from the enterprise side, where trust comes from guardrails and governance.

## Main themes

### Humans as the judges of agent work

- Megorskaya describes three eras of data work: simple labels for classical ML, PhDs and lawyers for foundation models, and complex, varied agent tasks that can take ten hours or several days per item ([Toloka](/podcasts/turing-post/2025/06/why-ai-still-needs-us-a-conversation-with-olga-megorskaya-ceo-of-tolok/)).
- She calls the shared work of humans and agents co-agency. Agents plan and check steps, while humans catch the roughly 30% of cases where the agent's plan is wrong, which she sees as the key signal ([Toloka](/podcasts/turing-post/2025/06/why-ai-still-needs-us-a-conversation-with-olga-megorskaya-ceo-of-tolok/)).
- Toloka now recruits practising professionals and trains them to distrust LLMs with labelled examples of right and wrong cases ([Toloka](/podcasts/turing-post/2025/06/why-ai-still-needs-us-a-conversation-with-olga-megorskaya-ceo-of-tolok/)).
- She says synthetic data has a ceiling, so Toloka uses hybrid pipelines where experts set a taxonomy, a synthetic skeleton is generated, and experts validate it. Public benchmarks leak fast, so companies commission private ones ([Toloka](/podcasts/turing-post/2025/06/why-ai-still-needs-us-a-conversation-with-olga-megorskaya-ceo-of-tolok/)).

### Trust earned one task at a time

- Boyd says delegation depends on the scenario. Low-risk tasks are handed over already, while some high-risk ones, such as major medical procedures, may never be ([Eric Boyd](/podcasts/turing-post/2025/06/when-will-we-fully-trust-ai-to-lead-a-conversation-with-eric-boyd-cvp/)).
- He describes agents taking on drudge work: an internal GitHub agent that upgraded a code base from Java 8 to Java 17, and Nuance DAX writing medical records from doctor-patient conversations ([Eric Boyd](/podcasts/turing-post/2025/06/when-will-we-fully-trust-ai-to-lead-a-conversation-with-eric-boyd-cvp/)).
- Boyd says it is still an open question whether AI that errs at human rates is acceptable, and for now the answer is often no ([Eric Boyd](/podcasts/turing-post/2025/06/when-will-we-fully-trust-ai-to-lead-a-conversation-with-eric-boyd-cvp/)).

### Guardrails and governance for enterprise agents

- Boyd thinks progress depends more on guardrails and enterprise controls than on model capability. One marketplace lets an agent issue refunds only up to a set amount, and the GitHub agent cannot check in or deploy code ([Eric Boyd](/podcasts/turing-post/2025/06/when-will-we-fully-trust-ai-to-lead-a-conversation-with-eric-boyd-cvp/)).
- Customers ask about governance and data leaks. Boyd points to Entra ID, which gives each agent an identity with centrally managed access ([Eric Boyd](/podcasts/turing-post/2025/06/when-will-we-fully-trust-ai-to-lead-a-conversation-with-eric-boyd-cvp/)).
- Both guests stay cautious about AGI. Megorskaya doubts a complete AGI would remove the need for human ground truth, and Boyd prefers to talk about useful tools, expecting agents to be common at work in two to five years ([Toloka](/podcasts/turing-post/2025/06/why-ai-still-needs-us-a-conversation-with-olga-megorskaya-ceo-of-tolok/), [Eric Boyd](/podcasts/turing-post/2025/06/when-will-we-fully-trust-ai-to-lead-a-conversation-with-eric-boyd-cvp/)).
