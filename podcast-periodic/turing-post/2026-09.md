## Overview

September on Turing Post was mostly Ksenia Se's Attention Span essays: one on NVIDIA's reported purchase of Hugging Face, one on how Meta's Muse agent is kept in check, and the first weekly news edition. The one interview took listeners inside OpenAI, where models now help optimise the stack that serves them.

## Main themes

### NVIDIA, Hugging Face and commercial openness

- Ksenia Se reports that NVIDIA has agreed to buy Hugging Face for almost $13 billion, about 86 times its roughly $150 million annualised revenue ([NVIDIA's $12.9B Plan](/podcasts/turing-post/2026/09/nvidia-s-12-9b-plan-to-rule-open-source-ai/)).
- She traces NVIDIA's habit of following developers back to NV1 and CUDA's lost years, and argues it opens tools and models so more workloads run on its closed platform ([NVIDIA's $12.9B Plan](/podcasts/turing-post/2026/09/nvidia-s-12-9b-plan-to-rule-open-source-ai/)).
- Se warns that Hugging Face grew by serving AMD, Intel, Google and Amazon, so its rankings and defaults would depend on NVIDIA's choices. Hugging Face later asked to join Dario Amodei's proposed evaluator scheme ([NVIDIA's $12.9B Plan](/podcasts/turing-post/2026/09/nvidia-s-12-9b-plan-to-rule-open-source-ai/), [AI That Acts](/podcasts/turing-post/2026/09/ai-that-acts-devin-fusion-persimmon-programmable-worlds-amodei-s-slowd/)).

### Agents that can change themselves, within limits

- Se describes Muse as Meta's free personal agent with its own cloud VM. Its apparent root maps to an unprivileged host user, and every network request passes through Sentinel, a permission system it cannot rewrite ([The Agent Can Rewrite Itself](/podcasts/turing-post/2026/09/the-agent-can-rewrite-itself-so-who-controls-it/)).
- Her principle is that capability can be fluid but authority cannot: “If a permission check lives inside a tool the agent can rewrite, then rewriting the tool can potentially rewrite the permission check” ([The Agent Can Rewrite Itself](/podcasts/turing-post/2026/09/the-agent-can-rewrite-itself-so-who-controls-it/)).
- Surrogate tokens and taint tracking add protection, but Se notes that classifiers can be wrong and permission fatigue is unsolved ([The Agent Can Rewrite Itself](/podcasts/turing-post/2026/09/the-agent-can-rewrite-itself-so-who-controls-it/)).

### Models that optimise their own serving stack

- Philippe Tillet and Matthew Ferrari say kernel improvements cut the end-to-end cost of serving GPT-5.6 by 20%. Ferrari links this to a roughly 20% API price cut ([Inside OpenAI](/podcasts/turing-post/2026/09/does-ai-understand-the-machine-it-runs-on-inside-openai/)).
- Tillet says the models were held back by Triton, so OpenAI built Gluon, a lower-level offshoot the models now mostly use ([Inside OpenAI](/podcasts/turing-post/2026/09/does-ai-understand-the-machine-it-runs-on-inside-openai/)).
- Kernels are easy to test, so the team leans on models there. Humans stay in the loop for the runtime and choose which bottlenecks matter end to end ([Inside OpenAI](/podcasts/turing-post/2026/09/does-ai-understand-the-machine-it-runs-on-inside-openai/)).

### AI that acts, and who watches it

- Alaya's programmable world model keeps a record of the world separate from the video: a coding agent writes a program and an engine updates the record ([AI That Acts](/podcasts/turing-post/2026/09/ai-that-acts-devin-fusion-persimmon-programmable-worlds-amodei-s-slowd/)).
- Cognition's Fusion pairs a planning lead model with a cheaper executor. A lead costing twice as much per token made sessions 9% cheaper on average ([AI That Acts](/podcasts/turing-post/2026/09/ai-that-acts-devin-fusion-persimmon-programmable-worlds-amodei-s-slowd/)).
- In Anthropic's review, Se notes, a monitor shown the model's reasoning flagged far less. “With the model's reasoning included, it flagged about 1% of the actions.” Without it, the figure was about 50% ([AI That Acts](/podcasts/turing-post/2026/09/ai-that-acts-devin-fusion-persimmon-programmable-worlds-amodei-s-slowd/)).
- Amodei proposed independent evaluators embedded in frontier labs; David Sacks called this business interest dressed as public service ([AI That Acts](/podcasts/turing-post/2026/09/ai-that-acts-devin-fusion-persimmon-programmable-worlds-amodei-s-slowd/)).
