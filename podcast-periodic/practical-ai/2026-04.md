## Overview

April on Practical AI centred on Anthropic: two hosts-only episodes dissected the Claude Code source leak and the withheld Mythos model. The two guest episodes looked at how AI coding agents strain the incentives behind open source, and at Comma AI's low-compute, open-source route to self-driving.

## Main themes

### The agent harness is the product

- Daniel Whitenack explains that installing Claude Code in a roughly three-hour window exposed a .map file, enough to rebuild about 500,000 lines of source, plus a malicious Axios package ([Claude Code leak](/podcasts/practical-ai/2026/04/post-mortem-of-anthropic-s-claude-code-leak/)).
- He argues “the real IP in these systems is actually not the model. It's this what's called the agent harness around the model.” Chris Benson adds that models matter less as many reach the same capability ([Claude Code leak](/podcasts/practical-ai/2026/04/post-mortem-of-anthropic-s-claude-code-leak/)).
- The leaked memory design uses a memory.md index of pointers, sharded topic files, strict write discipline and a nightly auto dream consolidation ([Claude Code leak](/podcasts/practical-ai/2026/04/post-mortem-of-anthropic-s-claude-code-leak/)).
- Whitenack advises treating harness dependencies as supply chain risk. Benson thinks Anthropic's best move is to open source Claude Code ([Claude Code leak](/podcasts/practical-ai/2026/04/post-mortem-of-anthropic-s-claude-code-leak/)).

### Anthropic under scrutiny

- The leak came weeks after the Department of Defense labelled Anthropic a supply chain risk and after an earlier leak about Claude Mythos. Benson says features such as decoy tools hurt a brand built on safety ([Claude Code leak](/podcasts/practical-ai/2026/04/post-mortem-of-anthropic-s-claude-code-leak/)).
- Benson describes Anthropic withholding Mythos after it found thousands of vulnerabilities and giving about 40 companies access. Whitenack recalls the gated GPT-3 release and does not think it is world ending, but sees a tailwind for AI governance ([Mythos and Allbirds](/podcasts/practical-ai/2026/04/the-mythos-of-mythos-and-allbirds-takes-flight-to-the-neocloud/)).

### Coding agents and open source incentives

- Miklós Koren argues agents break the open source reward model: usage rises while the humans who read docs, file bugs and give stars disappear. He calls human attention “a very scarce resource” ([Open source economics](/podcasts/practical-ai/2026/04/agentic-coding-and-the-economics-of-open-source/)).
- His experiment asked seven models to build 100 websites. Packages that models recommend gain downloads, while GitHub stars stay flat or fall ([Open source economics](/podcasts/practical-ai/2026/04/agentic-coding-and-the-economics-of-open-source/)).
- He cites Tailwind CSS, whose usage rose while site visits and revenue fell, and warns that unmaintained open source declines ([Open source economics](/podcasts/practical-ai/2026/04/agentic-coding-and-the-economics-of-open-source/)).

### Self-driving on a compute budget

- Harald Schäfer says Comma's models are end to end: they take video and output actions with no intermediate detectors. The policy now trains entirely inside a learned video simulator ([Comma AI](/podcasts/practical-ai/2026/04/open-source-self-driving-with-comma-ai/)).
- Comma runs about 100x less training compute than Waymo or Tesla, yet over 50% of users' miles are driven by the system. An external GPU is planned ([Comma AI](/podcasts/practical-ai/2026/04/open-source-self-driving-with-comma-ai/)).
- openpilot stays open source because the community ports it to new cars ([Comma AI](/podcasts/practical-ai/2026/04/open-source-self-driving-with-comma-ai/)).

### Hype checks on compute and metrics

- Allbirds sold its shoe business and rebranded as AI compute infrastructure. Whitenack calls roughly $50 million a drop in the bucket, and Benson expects more growth in embedded devices than in neoclouds ([Mythos and Allbirds](/podcasts/practical-ai/2026/04/the-mythos-of-mythos-and-allbirds-takes-flight-to-the-neocloud/)).
- The hosts call token-spend leaderboards a vanity metric, and warn that a court treated AI chat logs as not privileged ([Mythos and Allbirds](/podcasts/practical-ai/2026/04/the-mythos-of-mythos-and-allbirds-takes-flight-to-the-neocloud/)).
