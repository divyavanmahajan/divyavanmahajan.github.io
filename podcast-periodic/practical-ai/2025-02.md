## Overview

February on Practical AI was two hosts-only episodes that tried to cut through agent talk. Daniel Whitenack explained tool calling and agents from first principles, then he and Chris Benson listed the jobs generative AI does badly. Both landed on the same view: AI works best as an assistant with a human in the loop.

## Main themes

### Tool calling and agents, demystified

- Whitenack says there can be no direct link between an LLM, which only generates text, and a system like a CRM. Ordinary code takes the text and passes it into functions and APIs ([Tool calling](/podcasts/practical-ai/2025/02/tool-calling-and-agents/)).
- In his HubSpot example, “the LLM could generate the necessary arguments to call that function”, which then creates a deal through the REST API. Models fine-tuned on function-calling data do this better ([Tool calling](/podcasts/practical-ai/2025/02/tool-calling-and-agents/)).
- For Whitenack, what makes an agent is orchestration performed by the LLM: planning and sequencing several tools until it reaches a goal. At Prediction Guard he uses a web agent on legacy apps with no API, and agentic text-to-SQL that retries queries ([Tool calling](/podcasts/practical-ai/2025/02/tool-calling-and-agents/)).

### Where generative AI is the wrong tool

- Whitenack argues fully autonomous agents, such as one running a whole sales process, are fragile. The most successful systems he has seen are connected tools triggered by a human ([Hot takes](/podcasts/practical-ai/2025/02/genai-hot-takes-and-bad-use-cases/)).
- Pasting time series into a chatbot for a forecast ends badly because LLMs are weak with numbers; Benson adds high-stakes financial trading ([Hot takes](/podcasts/practical-ai/2025/02/genai-hot-takes-and-bad-use-cases/)).
- Whitenack warns against using GenAI for complete code rewrites and suggests treating Devin, Cursor and Windsurf as “junior developers that you are pairing with” ([Hot takes](/podcasts/practical-ai/2025/02/genai-hot-takes-and-bad-use-cases/)).
- Models work in perhaps the top five to ten of about 7,000 languages, and much tooling cannot handle right-to-left scripts such as Arabic. Purpose-trained vision models also beat general ones on fast inspection lines ([Hot takes](/podcasts/practical-ai/2025/02/genai-hot-takes-and-bad-use-cases/)).

### Moats, bundling and jobs

- Hugging Face reproduced OpenAI's Deep Research with open code in about 24 hours, which Whitenack takes as a sign that general applications are hard to defend without domain knowledge or proprietary data ([Tool calling](/podcasts/practical-ai/2025/02/tool-calling-and-agents/)).
- He argues Microsoft's Copilot gains from enterprise bundling, while sensitive data in pharma, healthcare and finance leaves room for vertical and infrastructure players ([Tool calling](/podcasts/practical-ai/2025/02/tool-calling-and-agents/)).
- Whitenack expects some jobs to shift but sees agents that handle tedious interfaces as expanding human agency. Benson notes the DOD's guardrails around AI in weapon systems ([Tool calling](/podcasts/practical-ai/2025/02/tool-calling-and-agents/), [Hot takes](/podcasts/practical-ai/2025/02/genai-hot-takes-and-bad-use-cases/)).
